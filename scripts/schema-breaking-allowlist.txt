# Format, one per line:   <rule> | <location glob> | <stability.md anchor> | <reason>
#   rule      one of the rule ids in the script header, or * for any
#   location  fnmatch glob against the location the gate prints on failure
#   anchor    a '###' heading under '## Current deprecations' in
#             packages/website/src/content/docs/api/stability.md - the gate FAILS if

#             published to integrators

# The baseline is the latest v* release tag, so entries go stale harmlessly when the
# next tag is cut and can be pruned then (the gate reports stale entries).
