- **Monte Carlo deltas no longer report a phantom ±3 days across a weekend** (#4204): when a project finishes on a milestone that a lag lands at the start of a Monday, the end of the Friday before it is the same point in working time, but every Monte Carlo delta subtracted the two shown days. Each percentile against the CPM finish (`delta_vs_cpm`), added time (`risk_premium_days`, and with it its ratio and state), the schedule-derivation `delta_vs_cpm_days`, the forecast history's run-to-run `delta` and the what-if `delta_vs_current` are now measured in working time, still in calendar days. The engine ranks percentiles by working-time finish and reports which edge of its day each one is (`p50_at_day_start` / `p80_at_day_start` / `p95_at_day_start`, plus `cpm_finish_at_day_start`), and each forecast run stores those readings. A run recorded before this change has no reading and is read as the end of its day.
