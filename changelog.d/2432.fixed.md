The demo loader (sidebar, Settings Demo data, My Work), the program seed import dialog, and the program import button now say "try again in N seconds" when the server rate-limits them (HTTP 429), using the `Retry-After` wait, and hold the button for that long instead of showing a generic failure. A zero, empty, or past `Retry-After` falls back to a short default wait, and very long waits are capped at an hour.
