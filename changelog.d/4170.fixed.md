The Schedule's drag, resize and keyboard-reschedule preview now steps through the project's own working week and holidays — the composed calendar the server schedules with, including layered calendars — instead of a fixed Monday–Friday week, so a bar moved across a holiday previews the date the commit lands on rather than snapping back when the CPM run completes. Project detail responses carry the calendar as a new read-only `scheduling_calendar` field, refreshed live when a calendar changes — `project_calendar_changed` now also fires when a project's applied calendars are replaced (`PUT /projects/{id}/calendars/`) (#4170).
