Celery tasks now run on two queues: long-running ones (MS Project, Jira and CSV import, project, program and workspace export, Monte Carlo, CPM recalculation) go to `heavy`, the rest stay on `celery`. The Helm chart gains an optional `heavyWorker` Deployment and an optional KEDA queue-depth `ScaledObject`; a stock install still runs a single worker consuming both queues. Workers you run yourself must pass `--queues=celery,heavy`.
