A recalculation the scheduler refuses (a Start-to-Start link from a summary task, or a dependency cycle) now ends cleanly for projects in a program too: the failed run is recorded and signaled on every member project, the outbox request is retired as done so the background drain stops re-running it, and the project is no longer stamped as recalculated. The System Health outbox card stays healthy; the failure is kept on the dead-letter card until an operator dismisses it, and a requeue from there re-runs the program pass. The dependency check also refuses a new Start-to-Start or Start-to-Finish link from a summary on a project that already holds one.
