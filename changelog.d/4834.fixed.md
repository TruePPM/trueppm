A recalculation the scheduler refuses (for example a Start-to-Start link from a summary task) now ends cleanly for projects in a program too: the failed run is recorded and signaled on every member project, the outbox request is retired as done so the background drain stops re-running it, and System Health no longer reports the outbox as critical. The dependency check also now refuses a new Start-to-Start or Start-to-Finish link from a summary on a project that already holds one.
