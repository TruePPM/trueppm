- **A shared-calendar edit now names who made it**: when someone edits a working-time
  calendar that your open project is scheduled against, a notice names them, so
  finish dates no longer appear to move by themselves. The editor does not see the
  notice for their own change. The audit log also records a `calendar_changed` row
  for a calendar rename or time-zone change (noting that no project was rescheduled)
  and for an edit to a calendar no project uses yet; both used to leave no record.
  The audit-log reference now lists every recorded event type.
