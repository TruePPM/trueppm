A phase's status is now rolled up from its leaf tasks on every schedule recompute (and exposed as read-only `status_source` / `status_rollup_count`), so successors of a completed phase are no longer shown as blocked. The baseline SPI no longer counts phase rows, so WBS granularity cannot move it. In the Grid and task drawer, a rolled-up phase status now reads as derived (dashed "rolled up" pill, no edit control, no Mark complete), and an empty phase shows an em dash instead of Not started.
