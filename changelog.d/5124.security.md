**Helm: the Ingress body ceiling is tight by default.** The main Ingress `proxy-body-size` is now `2m`, so unauthenticated routes such as sign-in, password reset, SSO, invite and share links no longer accept 110 MB at the edge. Two more Ingresses raise only exact, `$`-anchored routes to their application tier: `<release>-large-body` keeps `110m` for attachments and file imports, and `<release>-bulk-body` (`ingress.largeBody.bulkSize`) carries `10m` for logo, seed import, bulk, sync and inbound task push. If your values pin `proxy-body-size`, see the 0.5 upgrade notes.
