**Helm: the Ingress body ceiling is tight by default.** The main Ingress `proxy-body-size` is now `2m`, so unauthenticated routes such as sign-in, password reset, SSO, invite and share links no longer accept 110 MB at the edge. A second Ingress, `<release>-large-body` (`ingress.largeBody`), keeps `110m` for attachment, import, logo, bulk and sync routes. If your values pin `proxy-body-size`, see the 0.5 upgrade notes.
