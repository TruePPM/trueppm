Project and program **Visibility** is now enforced. **Private** (now the default) keeps a project or program members-only; **Workspace** lets any active workspace member find it and read its summary record, read-only, while its tasks, board, schedule and rollups stay members-only. Guests, deactivated accounts and draft projects are never exposed by it. Upgrading sets every existing project and program to Private — the access they already had — so nothing becomes visible until an Admin chooses Workspace. The Visibility control in General settings is enabled again (ADR-1434).
