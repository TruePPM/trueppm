Projects can carry a budget (BAC) and resources a single hourly cost rate, and TruePPM now computes actual cost from logged time (hours × the resource's current rate), earned value (budget × percent complete), cost variance and budget utilization. The program rollup's **Cost variance** and **Budget utilization** KPIs and the **Budget-weighted** aggregation policy now compute instead of being locked (#3426), and report an actionable reason (`no_budget`, `missing_rates`) when data is missing. New endpoints: `GET /api/v1/projects/{id}/cost/` (Project Manager) and `POST /api/v1/resources/{id}/rate/` (workspace admin; one endpoint previews and saves a rate change, which re-costs past hours). Rates and cost figures are never sent to a Member or Viewer; the program rollup's cost totals, and its budget weighting, apply only for someone who is Program Manager on the program and Project Manager on every project in it. A deactivated resource can still be rated, and a person whose account has no linked resource is priced by a resource with the same email. The workspace gains a `currency` setting (ISO 4217 label, no conversion). (#754)
