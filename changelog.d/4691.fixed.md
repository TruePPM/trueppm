- **Monte Carlo percentile before P50 on mixed calendars**: on a project whose tasks use their own calendars (for example a Monday-Thursday team on a Monday-Friday project), `monte_carlo()` could report a P95 earlier than P50, earlier than every run in `distribution`, and earlier than the CPM finish. The percentile had landed on a day no task works and was shown as the end of that day. A percentile with no run at its position is now shown no earlier than any run ranked below it, and P50 ≤ P80 ≤ P95 always holds. Single-calendar projects report the same seeded percentiles as before (#4691).
