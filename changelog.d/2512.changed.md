`GET /api/v1/me/work/` no longer returns `server_version_high_water`. It was the largest `server_version` across your tasks in several projects, which is not a valid sync cursor: one frequently edited task pushed it past every other task, so a client that sent it back as `?since=` would have lost those tasks for good. No client read it and the endpoint never accepted `?since=`. Offline clients should pull each project from `/api/v1/projects/{id}/sync/`.
