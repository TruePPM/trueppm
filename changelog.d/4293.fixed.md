Corrected the OpenAPI schema for four `@mention` group request bodies (project and program `add-member` and `remove-member`): `user` is now an integer user id instead of `format: uuid`. `deleted_by` (Trash list), `configured_by` (Git automation) and `assignee_id` (retro carryover) no longer claim to be UUIDs. The published `add-member` example now shows an integer id. Runtime behavior is unchanged.
