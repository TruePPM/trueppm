The interactive demo's chrome bar now states its own reset cadence (#4152):
"Sample data · resets daily at 08:00 UTC", plus the visitor's local time when it
differs, or "Sample data · resets periodically" for a non-daily schedule. Nothing
renders when the reset is disabled. The cadence is read from a new
`demo_reset_schedule` field on `GET /api/v1/edition/`, carrying the same cron
expression that drives the reset CronJob — so the bar can never state a schedule
that has drifted from the one actually running.
