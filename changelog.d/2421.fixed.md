A raw-JSON program seed (`POST /api/v1/programs/import/` and its `validate/` dry run) is now held to the same `SEED_MAX_UPLOAD_MB` as a multipart upload on every path. A declared `Content-Length` over the cap is refused before a byte is read, and a body that trips the global parse ceiling is reported as "Seed file too large" instead of falling through to an unbounded parse. A seed between 2 MB and the 5 MB default, above the new 2 MB global JSON ceiling, is still accepted as a raw JSON body.
