Public share pages (`/share/*`) are now served with `Referrer-Policy: no-referrer` by every shipped nginx config, so the share token in the page URL is not copied into `Referer` headers before the app loads. The same configs also replace the token with `[redacted]` in their access logs. Logs written by the API server, an ingress controller or a load balancer, and nginx's error log, are not redacted.
