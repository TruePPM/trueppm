`trueppm-scheduler`'s `monte_carlo()` takes a `deadline` (a `time.monotonic()` timestamp) and stops a simulation that runs past it with the new `SimulationTimeExceeded`, a `SimulationCapExceeded` subclass. The API passes `MC_WALL_CLOCK_BUDGET_SECONDS` (default 15 s) to the Monte Carlo run and what-if endpoints, which answer an overrun with HTTP 503 `simulation_time_exceeded` instead of running until the worker or ingress times out.
