The development Compose stack (`docker-compose.yml`) now publishes the API (`:8000`) and web (`:5173`) ports on `127.0.0.1` only, and generates a random JWT signing key on each API container start instead of deriving it from the public dev `SECRET_KEY`. Previously `docker compose up -d` exposed a `DEBUG`, `AllowAny` API with a forgeable token key on every host interface. If you reached the dev stack from another machine, use `docker-compose.prod.yml` or Helm; `TRUEPPM_DEV_BIND_ADDR=0.0.0.0` restores the old bind for isolated hosts only. A new `compose:ports` gate fails any non-loopback publish in `docker-compose.yml`.
