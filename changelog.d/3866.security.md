- **A failing extension provider no longer breaks community-edition requests**: every
  call into a registered extension provider (policy enforcement predicates, the
  signal-privacy default posture, calendar layer resolvers, SSO and portfolio hooks)
  is now contained, logged and replaced by a stated fallback, inside its own database
  savepoint. Public sharing, attachment upload policy and the forecast-history
  attribution audience fall back to the stricter value when the provider fails; the
  forecast-history retention cap keeps the larger value so nothing is purged on a
  guess; everything else falls back to the community behavior. Community installs
  register no provider and see no change.
