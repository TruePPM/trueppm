Task-link refresh no longer saves or broadcasts metadata fetched with another user's personal access token: provider-fetched titles and statuses are persisted to the shared link only when the link's creator refreshes it (or the provider needs no credential); other callers get the values in the response only. GitHub owner/repo path segments are now percent-encoded and `.`/`..` segments rejected. Links created before this release have no recorded creator, so their credentialed refresh no longer saves.
