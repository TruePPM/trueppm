A personal access token, share link, or other durable grant created by a request that was already running when a password reset committed could survive the reset's revocation sweep, because the sweep cannot see an uncommitted insert. Creating a personal, project, or program token, a share link, a git-automation secret, an outgoing webhook, or a workspace invite now locks the caller's profile row, the same row the reset locks, and re-checks the credential cutoff against the locked row. A creation that finishes first is revoked by the sweep, and one that starts after the reset is refused with a `401`.
