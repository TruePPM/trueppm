Settings → Templates now lists every template published from the project, using a new server-side `?source_project=` filter on `GET /api/v1/project-templates/`. Before, the page filtered only the first page of the workspace gallery, so a large gallery could hide a project's own templates. The template-divergence page also no longer says a template "has since been deleted": TruePPM has no way to delete a template, so it now says the template is no longer available.
