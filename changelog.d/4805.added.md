Status updates can be printed and shared: every project member can download a posted update as a one-page PDF in Letter or A4, drawn by the server from the update's frozen snapshot, and a Project Manager can create an expiring, read-only share link from the history. The share page needs no sign-in, shows no workspace navigation, follows light and dark mode, and shows the same "not available" page for an unknown, revoked or expired link. Behind `?ff=shell_v2`.
