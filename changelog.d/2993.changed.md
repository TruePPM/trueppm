- **Reading raw velocity is now the declared, unusual path (api)**: the ungated `velocity_summary` and `velocity_bands_for_projects` are renamed `velocity_summary_unfiltered` and `velocity_bands_for_projects_unfiltered`, and a new `velocity_summary_for(request, project_id)` returns the summary with the ADR-0104 privacy gate already applied. `/projects/{id}/velocity/` uses it. A new test walks the API source and fails on any reference to a raw or velocity-derived reader (`project_forecast`, `sprint_forecast`, `reforecast_preview`, `reforecast_bound_milestone` and the sprint-review velocity block, alongside the two raw accessors) that does not carry a `# velocity-unfiltered-ok: <reason>` comment, so a new endpoint cannot leak the team's velocity band without saying so at the call site. No response changes.
