- **Reading raw velocity is now the declared, unusual path (api)**: the ungated `velocity_summary` and `velocity_bands_for_projects` are renamed `velocity_summary_unfiltered` and `velocity_bands_for_projects_unfiltered`, and a new `velocity_summary_for(request, project_id)` returns the summary with the ADR-0104 privacy gate already applied. `/projects/{id}/velocity/` uses it. `POST /projects/{id}/sprints/generate/` returned the team's rolling velocity as `capacity_hint.points` to the PM band regardless of the velocity audience; it now returns `points: null` with `basis: "suppressed"` to a reader outside that audience. A new test walks the API source and fails on any reference, by name, to a listed raw or velocity-derived reader (`velocity_summary_unfiltered`, `project_forecast`, `sprint_forecast`, `reforecast_preview`, `reforecast_bound_milestone`, `capacity_hint`, `velocity_eligible_sprints`, and others) that does not carry a `# velocity-unfiltered-ok: <reason>` comment. The guard sees names only: the per-sprint `completed_points` fields on `SprintSerializer` are not covered by it.
