Hardened the `trueppm-mcp` HTTP/SSE transport: Host/Origin (DNS-rebinding) validation is now always enabled, including when bound to `0.0.0.0` as in a container, with `--allowed-host` / `TRUEPPM_MCP_ALLOWED_HOSTS` for reverse-proxy hostnames. Upgrade note: clients that reach a `0.0.0.0` bind by a non-loopback `Host` (a LAN IP, a Kubernetes Service name, `host.docker.internal`) now get `421` and must be named with `--allowed-host` or `TRUEPPM_MCP_ALLOWED_HOSTS`. The documented Docker recipe now publishes on the host loopback only (`-p 127.0.0.1:8000:8000`), and the `mcp` SDK floor is raised to 1.23.
