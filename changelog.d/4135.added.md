The scheduler library will accept `monte_carlo(targets=[...])` (up to `MC_TARGET_CAP`, 50) and return a `TargetForecast` with P50/P80/P95 per requested task, read from the same simulated runs as the project finish, so a target is never later than the project at the same level. The TruePPM app and API do not report per-milestone percentiles yet.
