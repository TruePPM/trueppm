The production Docker Compose stack could not serve anything: `nginx` failed to start because the collected-static volume was mounted *inside* the read-only frontend volume, at a path the web image does not contain — so the container never left `Created` while every other service reported healthy. Separately, the static assets `collectstatic` produced never reached the process that serves them, so the Django admin and API documentation stylesheets would have 404'd even once nginx started. Both are fixed, and the new prod-compose CI gate now asserts a real stylesheet is served on every run.
