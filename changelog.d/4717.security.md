The PyPI publish jobs no longer run unpinned build tooling while holding OIDC tokens: `scheduler`, `mcp` and `api` each split into a token-free build job and a minimal upload job, `hatchling` is pinned exactly in every `[build-system]` table, and `build`, `twine` and `pypi-attestations` install with `--require-hashes` from compiled lock files (#4717).
