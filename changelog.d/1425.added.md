The web app is installable as a progressive web app: a web app manifest with PNG and maskable icons, a service worker that precaches the application shell so it starts without a connection, and a branded launch screen when opened from the Home Screen. The worker caches no API response and never sees a sign-in token, an update never reloads an open page, and an `X-TruePPM-Service-Worker: disable` response header lets an operator remove the worker from every browser (#1425).
