A workspace **Agents** page, always linked from the shell v2 rail, lists every agent you can see across your programs, filtered by the server to your project memberships. Its controls work against the server: **Pause** refuses every call the agent makes until it is resumed, **Edit scope** sets Read and Dry run per area (Write is shown disabled and refused by the server until 0.6), and **Revoke token** stops the agent on its next call. An agent can never exceed the person it acts for, checked against that person's current roles on every call. Only that person or a workspace Admin can change an agent, never with an API token, and every change is recorded in the agent action log's hash chain. The page shows an "Action log verified" line, and a refused or paused agent call puts one coalesced item in its owner's Inbox. (#4814, #4757)
