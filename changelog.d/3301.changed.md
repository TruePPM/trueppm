Removed Board Workshop Mode. The feature shipped as a single-user surface — there was no way for a second project member to join an active session, so the live-presence collaboration its documentation described was never reachable. Rebuilding it as a real-time estimation surface was evaluated and rejected. The `workshops` API app, its four endpoints, its WebSocket channel, the `workshop_started` / `workshop_ended` events, and the Workshop Mode documentation page are all removed; a migration drops the two `workshops_*` tables. Phase rename and phase reordering are unaffected and remain available on the Workflow settings page.
