When a collaborator's CPM update moves dates inside the existing project bounds, the schedule canvas now skips rebuilding the background layer, the timeline header, and the time scale, and repaints only the bars layer. All bars and the dependency arrows are still redrawn, so this reduces repaint work but is not a per-bar partial repaint. A change to the project range, the critical-path set, row order, or any non-date field still takes the full repaint.
