- **Metric provenance**: each project health, forecast, load, risk, burn and slip
  figure now has one owning API endpoint (ADR-1314). The owning payloads return a
  `definitions` map with one sentence per figure and an `as_of` timestamp. For the
  Monte Carlo forecast, `last_run_at` is the as_of. The forecast also compares P80
  with a commitment: the active baseline's finish, else the program's target date.
  It returns `commitment_date`, `commitment_source` and
  `p80_delta_vs_commitment_days`, and the delta is null with a reason when it cannot
  be computed. The status summary gains a full `blocked_count`, and its
  `monte_carlo_p80` now always matches the forecast endpoint. The shell v2 P80
  tooltip shows the server's definition. See the new Metric vocabulary page.
  When the commitment is the program's target date, every project member who can
  read the forecast now sees that date, including members who are not in the
  program. Only the date is shown.
