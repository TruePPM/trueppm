- **Published api Docker images now match the tested dependency set**: `packages/api/Dockerfile` previously resolved dependencies with a fresh `pip install` against live PyPI, ignoring the checked-in `uv.lock` — so a published image could carry different package versions than the ones CI actually tested, even from the same commit. The image now installs from a hash-verified export of `packages/api/uv.lock` (the local scheduler package is still built from this checkout's own source, not the lock's registry pin), and boots (`django.setup()`) as part of every build. A new CI job, `api:image-lock-check`, builds the real production image and fails the MR if its installed set ever drifts from the lock again.
