Re-importing a program with **Replace** from the web UI (`POST /api/v1/programs/import/`) now keeps each project's key. The rebuilt projects take the keys of the projects they replace instead of getting a suffixed key such as `PLAT2`, so existing links like `/projects/PLAT/…` open the rebuilt project rather than the copy in Trash. If the rebuild fails, the projects in Trash keep their keys.
