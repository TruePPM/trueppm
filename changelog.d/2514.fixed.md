Three sync-protocol fixes. A `since` value or pagination cursor past the 64-bit integer range now returns `400` instead of `500` on both sync pulls. A save that names only server-owned counters in `update_fields` (a version-only "touch") now records its sync cursor, so the change reaches the next delta pull; `update_fields=[]` no longer advances the version. Clearing a retro action item's link when its promoted task is deleted now reaches offline clients on the next delta pull.
