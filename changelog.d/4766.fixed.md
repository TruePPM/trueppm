The weekly timesheet now shows every open task assigned to you (the same list My Work shows, minus completed tasks) as a row, even before you've logged any time against it. Previously the grid listed only tasks that already had time entries that week, so someone opening it to log their first hours saw an empty table. Which open tasks become rows depends on the week you're viewing; see the entry for #4783. The empty state now appears only when nothing is assigned to you and nothing is logged for the week, and names the week when it isn't the current one. If some of your assigned tasks can't be loaded, the grid says so instead of silently leaving them out.
