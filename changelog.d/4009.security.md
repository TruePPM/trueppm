- **Dead-letter queue and observability endpoints now require a workspace operator (superuser), not Django `is_staff`**: `FailedTaskViewSet` (dead-letter list/detail/requeue/drop, `requeue-all`/`drop-all`) and the observability app's System Health, Prometheus metrics (dead-letter, outbound email), retention policy editor, and telemetry-export endpoints moved from `IsAdminUser` to `IsWorkspaceOperator`. `is_staff` was an undocumented second admin axis that `WorkspaceRole` never governed; an `is_staff=True` account that is not also a superuser no longer has access to these surfaces. Superusers are unaffected.
