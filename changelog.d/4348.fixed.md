- **Helm demo overlay**: pinned `replicas.web` to 1 — the web tier is a static
  nginx SPA that gains no throughput from extra replicas, and every extra web
  pod only widened the blank-screen rollout window from #4341. Upgrade docs
  now also call out that an operator upgrading from `0.4.0-beta.7` with more
  than one web replica should scale the web tier to 1 before starting that
  specific upgrade, because beta.7 web pods cannot serve the next release's
  assets cleanly during the rollout.
