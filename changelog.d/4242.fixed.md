- **Project overview task counts no longer include phase rows**: `total_tasks`,
  `complete_tasks`, and `critical_task_count` on the project overview endpoint
  now exclude phase (WBS grouping) rows, matching the existing late-task-count
  behavior. A phase's status and criticality are rollups of its children, not
  facts about the phase row itself, so counting the phase alongside its
  children double-counted their contribution.
