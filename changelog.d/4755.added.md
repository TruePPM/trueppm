Shell v2 preview (`?ff=shell_v2`): `/home` renders a home chosen for your role (contributor, delivery, resource manager or executive). `GET /auth/me/` now returns `landing.home` and `landing.home_program`, and `PATCH /auth/me/profile/` accepts a `home_override` (`"rm"` or null) that a later `default_landing` write clears. With the flag off, landing is unchanged. The preview also adds a Monte Carlo forecast view at `/projects/<project>/forecast`: the server's P50/P80/P95 on the finish-date curve, its "as of", a run action, and "not run yet", stale and error states.
