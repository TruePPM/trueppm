Scheduling and Monte Carlo no longer refuse an all-agile project of about 1,750 or more stories with "Total project span … exceeds the maximum of 366000 days". The span guard used to charge every scrum story its velocity worst case as if all stories ran one after another. It now charges that worst case along the longest dependency chain. The Monte Carlo working-day index is sized the same way, so agile forecasts no longer build an index that runs centuries past the real finish. A hostile `story_points` is still refused, and a new limit keeps the total sprint horizon across all scrum tasks under 366,000 sprints (#4695).
