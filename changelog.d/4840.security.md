- **Changing a password from the Django admin now signs the account out everywhere**: the admin's change-password form (and its "disable password-based authentication" option) now revokes every refresh token and stamps the account's credential cutoff, so every access token and WebSocket ticket issued before the change is refused — the same sign-out the self-service password reset performs. `manage.py changepassword` is Django's own command and still only sets the password; the administration docs now say to follow it with `revoke_api_tokens --user <username> --commit`.
