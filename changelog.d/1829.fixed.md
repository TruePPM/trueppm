`monte_carlo()` now refuses a run whose sampled-duration matrix (`runs x tasks`) would exceed 250,000,000 cells with `SimulationCapExceeded`, instead of exhausting memory with a bare `MemoryError` on a large standalone run. The Monte Carlo and what-if API endpoints answer that refusal with HTTP 400 and the engine's message, not the 402 `tier: "team"` body the run and task caps return, because no tier raises it.
