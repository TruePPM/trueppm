- **`ProjectScopedViewSet` now fails closed for models with no project path**: the base queryset returned every row for a model lacking a `project`/`predecessor` foreign key, so a future task-scoped viewset calling `super().get_queryset()` would have been a silent cross-project IDOR. It now returns an empty queryset unless the viewset opts in with `unscoped_queryset = True`. No behavior change for existing endpoints.
