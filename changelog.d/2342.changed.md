The nightly tombstone reaper now also covers soft-deleted project memberships, retro action items, task links, suggested assignees and recurrence rules. Each gains a `deleted_at` column that records when it was deleted. Rows that were already deleted are stamped with the upgrade time, so each is kept for one full retention window after the upgrade before it is reaped.

Reaping a recurrence rule no longer hard-deletes the occurrence tasks it generated. That covers a rule removed on its own and one deleted with its template task; before this change, the template's reap took every occurrence with it. The reap now unlinks each occurrence from the rule first and publishes the change to sync clients, so the occurrences stay as ordinary tasks.
