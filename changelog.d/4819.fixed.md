- **A what-if pull-in that uses up a task's remaining work no longer finishes later on a start-to-start or start-to-finish link**: the task used to be left at zero duration, so its SS and SF links stopped measuring from its recorded start and a bigger pull-in could finish later than a smaller one (#4819). The engine now has an explicit input for open work with no remaining work, `Task.zero_remaining` (ADR-1474, decided on #5070): the task keeps its duration and percent complete, is placed as an instant, and its SS/SF links keep measuring from its recorded `actual_start`, or from the start its elapsed days imply. Both engines, Monte Carlo and `derive_value` read it. `Task.to_dict()` emits the key only when it is set, as the Rust engine does, so a network that does not set it produces the same document, schedule, Monte Carlo seed and percentiles as before; the 0.5.0-dev result-stability stamp is not re-blessed.
