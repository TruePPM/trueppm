The task drawer's over-allocation flag and the project attention feed's over-allocation items now count a task whose only assignment signal is its assignee (no unit-tracked allocation) as a full-time estimate, as the resource-assignment warning already does. The drawer flag also measures the load of resources linked to the assignee instead of every resource on a task they own, and a new `assignee_load_includes_estimate` task field reports when an estimated task is part of the over-capacity day. The attention feed discloses the estimate on the same terms, and its unit-tracked pass now reads the same open-task set as the estimate (backlog items, epics and recurring templates no longer add load).
