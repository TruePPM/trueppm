- **The Board lane header no longer states its progress twice.** Each phase swimlane
  drew an `h-1.5` progress track *and* printed the same percentage as a numeral beside
  it. The header now carries one progress slot: it renders the proportion as the bar,
  or — when the phase holds no committed work — as an em-dash, never both and never
  neither. The percentage moved to the bar's accessible name and to a tooltip that
  opens on hover, keyboard focus, and touch, so nothing that was readable before has
  become unreachable. A fully complete phase is now told apart from a nearly complete
  one by form rather than by four pixels of fill: 100% adds a detached hairline. A
  phase with no committed work renders no progress element at all, announcing itself
  to screen readers as "not applicable" — "indeterminate" would have been a different,
  and wrong, claim — and trades its colored rail for a neutral one. The cost row, when
  shown,
  stays in numerals under a dashed rule rather than adding a second bar (#3148).
