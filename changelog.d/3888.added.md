Project keys reach the agent surface and ⌘K. The `trueppm-mcp` server gains a `resolve_reference` tool that turns a cited key or reference (`PLAT`, `PLAT-T-10`, `PLAT-SP-3`, `PLAT-R-7`, a program key) into the UUIDs the other tools take, renamed keys included, and its instructions tell the model to cite tasks, sprints and risks by `qualified_id` rather than UUID. The ⌘K palette offers a **Reference** row when you type a reference or a key in capitals, resolved on the server, and finds a project by its current key. A reference you cannot see reads "No matches", the same as one that does not exist (#3888).
