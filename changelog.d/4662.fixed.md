- **Sprint list `?state=` documents and validates the real values (api)**: `GET /projects/{id}/sprints/?state=` was documented as accepting `CLOSED` and `CANCELED`, which matched nothing and returned an empty list. It now declares the model's values (`PLANNED`, `ACTIVE`, `COMPLETED`, `CANCELLED`) as an enum and returns 400 for any other value. `GET /users/search/` now declares its `q` parameter. The remaining bare-string vocabulary filters and undeclared query parameters are still open.
