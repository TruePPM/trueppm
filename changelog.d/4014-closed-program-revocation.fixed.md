Revoking a program API token works on a closed program again, and so does leaving a closed program yourself. The earlier fix that stopped deletes on a closed program's resources (#4014) had also blocked both. Removing another member from a closed program is still refused, and the program's **Access** settings now hide **Remove** on every row but your own. Program webhooks now follow the same rule: on a closed program you can no longer create or edit one, but you can still delete one. The program's projects keep sending events to its webhooks, so deleting a webhook is how you stop them without reopening the program.
