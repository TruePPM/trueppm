- **Scheduler: `trueppm_scheduler.engine` is now a subpackage (#4550)**: the
  8,800-line `engine.py` is split into an `engine/` package as a pure move,
  so scheduling output is unchanged and every name importable from
  `trueppm_scheduler.engine` on 0.4, private helpers included, is still
  importable through re-exports. A `mock.patch` / `monkeypatch.setattr` on an
  engine internal or a module constant (`MAX_DEPENDENCIES`, `MAX_EXPANDED_EDGES`)
  must now target the submodule that calls or reads it, or it silently patches
  nothing. Moved classes report the new submodule in `__module__`
  (`trueppm_scheduler.engine.results` for `ScheduleResult`), and a result pickled
  by 0.5 will not load on 0.4 (0.4 pickles still load on 0.5).
