Close the DNS-rebinding window in the SSRF egress guard: for direct egress the connected peer address is now re-checked against the deny-list after the TCP connect and before TLS or any request byte. Covers webhook delivery and every integrations egress call (SSO discovery, JWKS, token exchange, GitHub OAuth/user, Jira external sources, link previews, git-link refresh, PAT verification). Requests routed through `HTTP_PROXY`/`HTTPS_PROXY` keep only the advisory resolve-time check (the proxy must enforce egress) and log a one-time warning; behavior for proxied installs is unchanged. SMTP is tracked separately in #4647.
