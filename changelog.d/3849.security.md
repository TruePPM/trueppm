Close the DNS-rebinding window in the SSRF egress guard: for direct egress the connection now resolves once, refuses any non-public answer without connecting to it, and re-checks the connected peer, all before TLS or any request byte (an open and a closed internal port are indistinguishable). Covers webhook delivery and every integrations egress call (SSO discovery, JWKS, token exchange, GitHub OAuth/user, Jira external sources, link previews, git-link refresh, PAT verification). Requests routed through `HTTP_PROXY`/`HTTPS_PROXY` keep only the advisory resolve-time check (the proxy must enforce egress) and log a one-time warning; behavior for proxied installs is unchanged. SMTP is tracked separately in #4647.
