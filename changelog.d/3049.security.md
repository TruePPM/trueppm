Link creation now enforces the workspace/program/project "Public sharing" policy (ADR-0135) inside the share-link mint routine itself — including the pinned-token path of `create_demo_share_link` — so no caller other than the share endpoint can create a public link while sharing is off. The share endpoint returns its usual 403 if the policy flips off mid-request. Behavior change: the sample-data loader now skips the sample share link (Aurora) when Public sharing is off, which is the default; turn it on in Workspace Settings before loading to get the link.
