- **Monte Carlo no longer charges a full working day to a zero-duration task with a small estimate**: a 0-day task with a three-point estimate such as `(0, 0, 1)`, mean 1/6 day and mode 0, was floored at one working day in every run, so P50 moved one working day past the CPM finish even though most runs sampled almost nothing. Milestones arriving with PERT fields, for example from an MS Project import, each added a day of guaranteed slip. A draw that rounds away is now the same instant `schedule()` places, including how its links and lags measure. A larger draw stays ordinary work, the same as a task of that length with the same link, so an FF or SF link into the task can still put a run before the CPM finish (#4822). **Seeded Monte Carlo results change for zero-duration tasks with a sampled duration**: three-point estimates, and in principle story points on the velocity path, where whole-sprint draws showed no change when measured. Tasks with a duration of one day or more are unaffected, as are zero-duration tasks with neither an estimate nor a velocity signal.
