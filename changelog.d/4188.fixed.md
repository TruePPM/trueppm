Workspace-invite and export-ready emails no longer carry a broken relative link when `TRUEPPM_FRONTEND_BASE_URL` is unset — the invite/export/notification-preferences link is now omitted with an explanation instead of emitting an unclickable `/path...` string. A `manage.py check --deploy` warning and a Helm post-install notice now flag an unset `TRUEPPM_FRONTEND_BASE_URL`, and the dev Docker Compose `celery`/`celery-beat` services now carry the same setting as `api`.
