The shell health chip now shows the project's health band word — On track, At risk, or Critical — instead of its own wording. A project with a critical task read "At risk" in the top bar while the page beneath it read "Critical", and a project with at-risk tasks read "On watch", a word that appeared nowhere else in TruePPM. The band word is now read from one shared source, so the top bar and the page can no longer disagree.
