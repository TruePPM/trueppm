Earned value on the project cost summary weights each task's percent complete by its duration, so a 100-day task counts 100 times as much as a 1-day task (ADR-1447). Only leaf tasks count: phases, backlog items, epics, recurring tasks and milestones are left out, and a task with subtasks counts at the percent complete its subtasks roll up to, as the task shows it but counting only its subtasks, not backlog or epic items filed under it. A project whose tasks have no duration in total reports `no_planned_duration` for earned value, cost variance and the forecasts; budget utilization still computes. The program rollup's cost variance leaves such projects out of its total and counts them, shown as "N projects not yet scheduled", and is unavailable only when every project is in that state. The cost summary's `percent_complete` is this weighted figure, which can differ from the project list's percent complete.
