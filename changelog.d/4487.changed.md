**Helm: `alerts.thresholds` age keys are now Prometheus duration strings.** `backup.staleAfter` (`48h`), `demoReset.staleAfter` (`26h`) and `outboxOldestAge` (`15m`) replace the integer-second `backup.staleAfterSeconds`, `demoReset.staleAfterSeconds` and `outboxOldestAgeSeconds`, matching the `*For` keys beside them. The old integer keys are deprecated but still render the same rule for one minor; the new key wins if both are set. `values.schema.json` rejects an integer under a new key and a string under an old one.
