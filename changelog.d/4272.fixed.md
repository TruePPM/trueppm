- **Scheduler: a lagged finish-to-finish or start-to-finish link into a milestone no longer pushes it a working day late**: a milestone has no working day to occupy, but a lagged FF or SF link into one snapped it forward as if it did. With the lag crossing a weekend or holiday, the milestone landed a working day after the same finish-to-start link would place it, and moved everything behind it, the project finish included. A milestone now sits on the instant the link names, so an FF link into it schedules exactly as FS does. The late dates and float of the tasks feeding it follow the same rule. The browser's drag preview applies it too (#4272).
