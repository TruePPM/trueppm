- **`repr()` of `Project`, `ScheduleResult` and `MonteCarloResult` is now one bounded line (scheduler)**: counts, dates and the first few ids replace the full dataclass dump, which ran to 26 KB for a 50-task project and megabytes at scale. `eval(repr(x))` no longer rebuilds these three types; use `to_dict()` / `from_dict()` for the full-fidelity form. `Task`, `Dependency` and the small value types keep the dataclass default. Also adds boundary tests for every exported `MAX_*` input cap and fast direction tests for the calendar snap helper.
