- **`trueppm-scheduler`: `monte_carlo()` no longer finishes a working day late
  when a Start-to-Finish link places work before the project start (#4510)**: a
  live milestone whose recorded actual start, start-no-earlier-than date or data
  date lies before the project start measures its links from that earlier date, so
  `schedule()` places its Start-to-Finish successor before the project start too.
  `monte_carlo()` opened its working-day index only far enough back for the
  milestone's incoming links, so the successor fell off the front of the index,
  was placed on its first day instead, and could push P50/P80/P95 one working day
  past the deterministic finish on a project with no uncertainty at all. The index
  now also reaches back to those milestone floors.
