A hard 1 MB request-body limit now applies at the edge to the anonymous inbound Git-event receiver (`/api/v1/integrations/projects/<id>/git-webhook/`). The chart renders a dedicated `<release>-git-webhook` Ingress with `proxy-body-size: 1m` (`ingress.webhookBodyLimit`) and a 1M web-tier nginx location, so an anonymous caller can no longer push the 110 MB attachment ceiling at an unconfigured project before the app's own cap runs.
