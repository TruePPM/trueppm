The Helm production web-nginx branch and the published `web` image's `nginx.conf` now forward `X-Forwarded-Proto` (honoring an inbound value via the shared `$forwarded_proto` map) and `X-Forwarded-For` on `/api/` and `/ws/` (and, in the Helm production branch only, its allowlisted `/admin/` proxy; the baked image's `/admin/` stays a 404), so a TLS-terminating load balancer in front of the web tier no longer makes Django see plain HTTP. The nginx parity gate now requires every proxied `/api/` and `/ws/` location to forward the scheme.
