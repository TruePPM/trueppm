- **API tokens now default to the `api:full` scope**: a personal, project or program token minted without `scopes` now carries `["api:full"]` instead of `["legacy:full"]`, and the token create forms send `api:full`. `legacy:full` is the same scope under its original name — existing tokens keep it and keep working unchanged, it is still accepted when minting and echoed back as sent, and both names authorize exactly the same routes. New integration scripts should send `api:full` so a later scope taxonomy can retire the `legacy:` name without breaking them.
