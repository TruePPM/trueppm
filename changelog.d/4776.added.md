- **Seed schema 2.2 carries the program decision log**: a program export now includes `program.decisions` (owner, due date, status, decided-at, linked task or risk, impact note, and the original created/updated times), and importing the file restores them. An export with no decisions keeps its 2.0 or 2.1 version string, so it still imports into a build that predates 2.2.
