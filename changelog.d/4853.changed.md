Earned value on the project cost summary now weights each task's percent complete by its duration: a 100-day task counts 100 times as much as a 1-day task (ADR-1447). Phases, subtasks, backlog items, epics, recurring tasks and milestones are left out, so phase work is no longer counted twice. A project whose tasks have no duration in total reports `no_planned_duration` for earned value, cost variance and the forecasts instead of an earned value of 0, and the program rollup's cost variance names how many projects are affected. Budget utilization is unaffected. The cost summary's `percent_complete` is this weighted figure, which can differ from the project list's percent complete, and the cost contract version is now `2`.
