A recalculation that hits stored input the scheduler refuses (for example a Start-to-Start link from a summary task, which older writes and some structural edits can still leave behind) now ends the task cleanly instead of failing it: the run is recorded as failed with the scheduler's message, and the project's outbox request is retired so the background drain stops re-running it every ten minutes. The next edit to the project schedules a fresh recalculation.
