The phase color picker and both status color pickers (project workflow settings and board column settings) now offer the same set of colors, with Lime and Pink added (saved colors are unchanged). The board's phase rail uses a subset of that set with no red, no gray and no near-identical hues, so some rails take a new hue. Settings buttons use the shared button style. The Decisions log is reachable from the command palette ("Go to Decisions"), from a "View Decisions" button on the new note-flag confirmation, and at `/projects/:id/reports?tab=decisions`.
