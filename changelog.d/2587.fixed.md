A deleted program can now be recovered. `GET /api/v1/programs/trash/` lists the programs you were a member of that have been deleted, and `POST /api/v1/programs/{id}/restore/` (Program Admin) brings one back with the projects its delete detached re-attached. This covers programs replaced by a seed re-import too, which come back under a fresh code. There is no program Trash page in the web app yet; recovery is through the API.
