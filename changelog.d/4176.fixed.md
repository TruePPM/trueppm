`Calendar` exception runs are now coalesced across any gap that contributes no mask-working day (e.g. a weekend), not just overlap/adjacency — a "closed until further notice" period written as thousands of weekly Mon-Fri ranges (as an MSPDI import or an RRULE expansion produce) now snaps and computes working-day spans in O(log E) instead of once per week. Follow-up to the #4161 single-long-exception fix, which this class of input did not benefit from. Both the Python (`trueppm-scheduler`) and Rust/WASM engines are updated in conformance.
