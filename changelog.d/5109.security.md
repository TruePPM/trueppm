- **Every agent-token revoke is now in the agent action chain**: revoking an agent's token from personal, project or program token settings, from a password reset or off-boarding sweep, or with `manage.py revoke_api_tokens` now appends an `agent.revoke` row to the tamper-evident chain the agent's own calls are recorded in, in the same transaction as the revoke, naming who revoked it (or a server operator) and the reason. Before, only the Agents page wrote one, so an agent stopped any other way simply went quiet in the log. Tokens with full API access are not agents and keep only their token audit row.
