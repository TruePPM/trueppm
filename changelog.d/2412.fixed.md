The dead-letter requeue and bulk-action endpoints now publish the response shapes they actually return: `POST /api/v1/admin/failed-tasks/{id}/requeue/` declares the `workflow_id` it already sent (as `FailedTaskRequeueResult`), and `requeue-all` / `drop-all` declare `{ processed, matched, capped }` (as `FailedTaskBulkActionResult`) instead of a free-form body. The System Health docs no longer describe the console as read-only, and state that its triage actions need a workspace operator account rather than a workspace admin. (#2412)
