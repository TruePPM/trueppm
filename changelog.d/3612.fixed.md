The project Activity feed now folds identical consecutive changes into one row with a count, shows what each field changed from and to (for example "Status: Not started → In progress"), and labels each row by what it is (Mitigation, Milestone, Story, Bug) instead of calling every task-backed row "Task". The changelog API gains `object_kind` and `object_kind_label` on each entry. A choice field's change also carries `old_display` and `new_display`, the current label for each side (absent for a non-choice field, a null side, or a retired code; labels come from the current code's choices, not the history row), on the changelog and on the per-object history endpoints.
