Eight write surfaces now show the server's own reason when a save is refused, and only offer a retry where a retry could help. The bulk-edit sheet, the schedule commit popover, the task/epic/story/program-backlog detail drawers and the mobile Monte Carlo card previously replaced every refusal — a permission denial, a validation error, a rate limit — with one hardcoded sentence, and three of them relabeled their primary button to "Retry" on a `4xx` the server had already decided. The bulk-edit sheet's error is now a live region, so a refused batch is announced rather than silently drawn. The shaping has a single definition (`describeWriteRefusal`).
