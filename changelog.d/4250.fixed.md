- **Status/health triage counts and the MCP schedule summary no longer include
  phase rows**: the TopBar/StatusBar `status-summary` and My Work
  `health-summary` endpoints' `critical_count` and `at_risk_count`, and the
  `get_schedule_summary` MCP tool's `critical_task_count`, now exclude phase
  (WBS grouping) rows — the same fix #4242 applied to the project overview. A
  phase's `is_critical` and `total_float` are rollups of its children, not
  facts about the phase row itself, so counting the phase alongside the
  children whose rollup produced its value double-counted their contribution.
- **New task-list filter `?is_phase=true/false`**: lets a client select or
  exclude phase (WBS grouping) rows directly, the same semantics used
  internally by the triage-count fix above.
