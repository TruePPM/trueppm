A narrow `webhooks:manage` personal-token scope lets a CI bot or integration create, read, update, delete, and test-ping outbound webhooks (project and program scope) without a full-access token. It acts as its owner under the owner's Admin role, authenticates only on the webhook routes, never reads the delivery log, and cannot be combined with another scope. It can still point a webhook at any URL and so receive future event payloads; revoking the token deactivates every webhook it registered, repointed, or re-enabled. It is minted by API call only.
