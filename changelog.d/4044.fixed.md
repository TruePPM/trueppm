- **Web images now get their SBOM attestation**: `web:publish` and `web:publish:arm64` wrote the CycloneDX SBOM to `packages/web/sbom/` (they run `cd packages/web` first) while the job's artifact path and `web:publish:manifest` read the project-root `sbom/`. The upload printed "no matching files" and the job still passed, so `web:publish:manifest` failed at `cosign attest` after the multi-arch index was already signed, and `ghcr.io/trueppm/web:0.4.0-beta.4` shipped with no per-arch SBOM attestation (the `api` image was unaffected). Both jobs now write to `${CI_PROJECT_DIR}/sbom` and fail on the spot if the SBOM is missing or empty, so a broken path can no longer pass silently (#4044).
