OpenAPI no longer advertises API-token auth on the webhook create/update, share-link create and resource rate-change operations that refuse tokens, and now declares the optional `Idempotency-Key` request header, the `Idempotent-Replay` response header and the shared `422` key-reuse response on every mutating operation that honors idempotency (#4665). Path parameters named `id` or `*_pk` now carry `format: uuid` (#4093).
