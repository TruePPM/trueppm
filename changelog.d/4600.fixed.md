Task write paths that previously broadcast a bare `task_updated` frame (subtask parent, estimate approval, suggestion accept, acceptance criteria, recurrence rules, phase edits, DoR transitions, CI acceptance ingest) now carry `changed_fields`, `version` and `actor_id`. `version` is `null` when only a child row changed, and `actor_id` is set only where the editing client already refreshed its own task list, so every other client, including the editor's, still refetches.
