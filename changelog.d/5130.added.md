- `GET /api/v1/projects/{id}/forecast/` returns `headline_forecast_kind` (`cpm_monte_carlo`, `team_velocity`) and `headline_forecast_reason` (`sparse_dependency_network`, `no_sprints`, `no_scheduled_tasks`, `dependency_network`, `no_velocity_forecast`, `velocity_withheld`), chosen by the server per caller. A new `schedule.finish_changed` webhook event fires when a project's headline kind switches. It is sent only when the team shares the `velocity` signal outward (`program_shared`); under the default audience it is not sent.
