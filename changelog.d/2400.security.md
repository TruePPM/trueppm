Export bundles can be encrypted at rest, opt-in per export. The project and program **Export bundle** cards (and `POST …/export/` with an `encryption` body) encrypt a bundle with a passphrase or to an age public key, in the age v1 format. TruePPM never stores the passphrase or a digest of it: the passphrase is removed from a request before it is hashed for an `Idempotency-Key` or the agent audit trail, and a job keeps only a public key derived from it, cleared once the bundle is built. Passphrase mode gives confidentiality, not authenticity. An encrypted bundle downloads as `.tar.gz.age`, and program import accepts a passphrase bundle with its `passphrase`. The JSON seed export stays unencrypted because it is never stored on the server.
