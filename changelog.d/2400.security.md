Export bundles can be encrypted at rest, opt-in per export. The project and program **Export bundle** cards (and `POST …/export/` with an `encryption` body) encrypt a bundle with a passphrase or to an age public key, in the age v1 format. TruePPM never stores the passphrase: it keeps only a public key derived from it. An encrypted bundle downloads as `.tar.gz.age`, and program import accepts a passphrase bundle with its `passphrase`. The JSON seed export stays unencrypted because it is never stored on the server.
