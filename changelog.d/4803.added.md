Project status updates in the API: a Project Manager posts a RAG call and a short narrative, and the server freezes a snapshot of the plan beside it (P50, P80, CPM finish, baseline variance, milestones, completed and slipped counts since the previous update, top risks, open decisions, and the computed health). Updates are immutable and numbered per project; the history returns, per figure, the current value where the plan has moved since. A share link can be bound to one update and serves that frozen snapshot only. `GET/POST /api/v1/projects/{id}/status-updates/`, `GET /api/v1/projects/{id}/status-updates/{update_id}/`, `GET /api/v1/share/status-update/{token}/` (#4803).
