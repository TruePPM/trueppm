- **`expand_summary_dependencies` input validation**: a `children_map` child id that names no task is now refused with an `InvalidScheduleInput` naming the `children_map` entry (when a task list is supplied), instead of surfacing later as an "unknown task" error on an edge the caller never wrote. The function and `schedule()` docstrings now list every `InvalidScheduleInput` cause. A task listed under two parents remains accepted (diamond maps are a supported shape).
