- **Program rollup critical/at-risk totals no longer include phase rows**: the
  program rollup's `critical_tasks`/`at_risk_tasks` totals, the weekly
  program-health digest's worst-project tie-break, the program directory's
  per-project `overdue_count`/`at_risk_count`, and the project attention
  panel's baseline-drift list now exclude phase (WBS grouping) rows — the same
  fix #4250 applied to the single-project status/health triage counts. A
  phase's `is_critical`/`total_float`/`early_finish` are rollups of its
  children, not facts about the phase row itself, so counting the phase
  alongside the children whose rollup produced its value double-counted their
  contribution.
