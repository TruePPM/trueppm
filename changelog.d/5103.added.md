Project Overview: the API's `GET /projects/{id}/overview/` now serves `over_allocated_count` (people over 100% load on this project in a week of the next 8, time off removed; withheld below Scheduler or when the team does not share its capacity signal with the caller) and `changes_since` (this Monday 00:00), each with a definition. The shell v2 Overview adds the Over-allocated tile, a "Changes since Monday" feed from the project change history, and an on-demand driver chain behind "Why this date?".
