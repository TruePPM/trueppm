Imported MS Project and CSV files that link a summary task to a task nested inside it (in either direction) are now refused at import, with a message naming the tasks or rows, instead of being saved and failing every later recalculation. The same check now runs on the Jira importer (defense in depth: the Jira parser produces a flat outline today) and on project template publish and apply, so a template cannot carry a cyclic or summary-to-subtask link into other projects. Templates already published with such a link now refuse to apply (a 400 naming the problem) and must be republished once the links are fixed in the source project.
