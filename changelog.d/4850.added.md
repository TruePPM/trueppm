- **Cost line in the weekly program-health digest**: each program line now says whether the program is over budget, spending ahead of progress, or within budget. The band appears only when a cost KPI is turned on in the program's rollup, and only for a recipient who is Program Manager or above on the program and Project Manager or above on every project in it; anyone else is told why there is no band. The digest never contains a cost amount, ratio or count. A program that is over budget is now listed even when its schedule is on track.
