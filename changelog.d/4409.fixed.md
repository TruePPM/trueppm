- **Helm**: `values-prod.yaml` keeps the web tier at two pods, following
  `replicaCount`, so a node drain no longer takes the UI down. The comments
  and docs that said a single web pod closes the rolling-update version-skew
  window are corrected: Kubernetes' default rolling update surges a new pod
  before the old one stops, so the window opens briefly even at one replica.
  The client recovers from that window on its own (#4408) (#4409).
