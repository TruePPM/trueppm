- **P50 and P80 cost from the Monte Carlo** (#4809): Each simulated schedule is priced as actual cost to date plus every open task's remaining assigned hours at each person's current rate, from the same runs as the date percentiles. The project cost breakdown (`GET /api/v1/projects/{id}/cost/`) gains `p50_cost` and `p80_cost`, each with `as_of`, `n_simulations` and a definition, and a reason (`missing_rates`, `no_simulation`) instead of a number when it cannot be computed. Each also carries the run's `actual_to_date` and a `stale` flag, true when the actual cost has changed since; the percentiles are not adjusted. In `trueppm-scheduler`, `monte_carlo()` takes an opt-in `cost=CostModel(...)` and returns a `CostForecast` on `MonteCarloResult.cost`; the dates do not change.
