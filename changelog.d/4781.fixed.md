The WASM scheduler's cyclic-dependency error now matches the Python engine: task ids are `repr()`-escaped, the message lists at most 10 ids followed by `… (+M more)`, and the reported cycle is canonical (smallest id's strongly connected component, shortest cycle through that id). Ids made of assigned characters produce a byte-identical message and cycle in both engines; the only known difference is that unassigned code points and format characters newer than Rust's built-in list are printed verbatim by Rust where Python escapes them.
