**S3 attachment storage now actually works.** `django-storages` was not a dependency of the API, yet the configuration reference, the Helm README, a shipped `values.yaml` comment, and `.env.example` all told operators to set `TRUEPPM_DEFAULT_FILE_STORAGE=storages.backends.s3.S3Storage` — and production refuses to boot on the ephemeral local default (#775), so the boot guard steered operators at the one value the image could not import. The S3 backend now ships in the image, and the bucket is configurable via `TRUEPPM_S3_BUCKET_NAME` plus `TRUEPPM_S3_ENDPOINT_URL` / `TRUEPPM_S3_ADDRESSING_STYLE` / `TRUEPPM_S3_REGION_NAME` / `TRUEPPM_S3_ACCESS_KEY_ID` / `TRUEPPM_S3_SECRET_ACCESS_KEY` / `TRUEPPM_S3_SIGNATURE_VERSION` / `TRUEPPM_S3_QUERYSTRING_EXPIRE`. Credentials are optional so an EKS deploy can use IRSA or an instance profile instead of static keys. Two new startup checks replace opaque runtime failures: `trueppm.E007` names the exact package to install when the configured backend cannot be imported (GCS and Azure Blob are recognized but not bundled), and `trueppm.E008` catches an S3 backend with no bucket rather than letting the first upload fail on `Required parameter name not set`. Presigned URLs now default to SigV4 — without an explicit signature version the SDK falls back to SigV2, which AWS rejects in regions created after 2014 — and `file_overwrite` is disabled so two people uploading `report.pdf` to one task no longer destroy each other's attachment. The attachment **Get signed download URL** action now applies its `?ttl=` to the signature rather than only to the reported `expires_at`: that code path was unreachable while no S3 backend was installed, and shipping one would otherwise have made it live with a URL that expired after the backend default (900s) while the response claimed up to the requested 3600. A new `api:s3-drill` CI job exercises the documented configuration against a live MinIO service, asserting the round-trip, that the presigned URL downloads unauthenticated, and that an unsigned URL is denied. Closes #2559.
