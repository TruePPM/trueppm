- **Observability docs now name the HTTP request-latency metric TruePPM actually emits**: the docs and ADR-0223 documented the histogram as `http.server.request.duration` (the stable HTTP semconv name, in seconds), but `opentelemetry-instrumentation-django` runs without `OTEL_SEMCONV_STABILITY_OPT_IN` and emits the older `http.server.duration` in milliseconds instead — behind a Prometheus exporter, `http_server_duration_milliseconds_*`, never `http_server_request_duration_seconds*`. An alert or dashboard built on the documented name would silently never fire. No metric was renamed — that would break dashboards already built against the metric TruePPM has shipped since #710.
