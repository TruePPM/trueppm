Project and program membership roles are now constrained at the database to the ADR-0072 band (Viewer through Owner), so a stray ordinal can no longer exceed Owner authority; an in-band custom-role ordinal no longer 500s the project member list (the project side now has the same safe role label the program side already had). Out-of-band rows are repaired by the migration (below Viewer becomes Viewer; above Owner becomes Owner, or Admin for group and default-member roles).
