- **`trueppm-scheduler` Monte Carlo default is now 10,000 runs**: `monte_carlo(project)` previously defaulted to 1,000 runs while the `monte-carlo` CLI defaulted to 10,000. Both now default to 10,000 (`DEFAULT_RUNS`); pass `runs=1_000` to keep the old library behavior. The README also now states that `is_critical` is `total_float == 0` on live work only (completed work has zero float and is never critical), and documents the concurrency guarantee (`schedule()`/`monte_carlo()` are pure; a shared `Calendar` is not synchronized).
