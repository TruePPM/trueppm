`hidden_views` on `/api/v1/auth/me/` and `/api/v1/auth/me/profile/` is deprecated (`Deprecation` and `Sunset` headers, `deprecated: true` in the schema) and is removed in the release after 0.5. Reads now return only the views you hid yourself, across your projects. Writes apply to every project you belong to. Existing hidden views were copied into each of your projects as your own choices, so no view reappears. The methodology starter rail for a first project is replaced by View focus suggestions.
