The git-webhook receiver no longer loads a full `Task` row for every task link in the project on each delivery: it reads only the URL and task id of links for the delivering provider, fetches the one matching task by primary key, and a new partial index on live task links by provider backs the lookup.

Task links stored with the `generic` provider (a self-hosted GitLab or GitHub Enterprise Server URL added by a user with no matching connected-account credential) are no longer candidates for the receiver, so they stop moving cards.
