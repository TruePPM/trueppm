- **Dependencies that collide after summary expansion**: creating or editing a
  dependency so that it lands on the same pair of leaf tasks as an existing link of
  a different type (for example `A -> C` Finish-to-Finish beside `Phase -> C`
  Finish-to-Start, where `A` is inside `Phase`) now returns a 400 on `dep_type`
  naming the conflicting links, instead of returning 201 and failing every later
  schedule recalculation.
