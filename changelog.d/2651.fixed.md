The `lint:design-system-v2` hex ratchet no longer counts an issue reference as a
hardcoded color. The pattern matched a `#` preceded by a quote, bracket, or colon,
so a comment like `the "#2495 scope boundary" test` registered as a color literal
and failed branches that added none. It now also requires the hex run to be
*closed* by its own delimiter, which prose never is. `BASELINE_HEX` re-anchored
121 → 117. The gate additionally self-tests its pattern against known colors and
known issue references before counting, so a malformed pattern fails loudly
instead of reporting zero and passing.
