- **Three endpoints published an OpenAPI response type they never returned, breaking
  generated SDKs on the first call.** `GET /api/v1/sprints/{id}/duration-events/`
  advertised a `Sprint` while returning `{events: [...]}`;
  `GET /api/v1/workspace/audit-events/` advertised a bare array while returning the
  cursor envelope `{next, previous, results}`; and
  `GET /api/v1/projects/{project_pk}/history/` declared no response body at all
  while returning a pagination envelope. Each now declares its real payload, and
  the per-sprint duration-change feed is documented in the API reference for the
  first time. The runtime responses are unchanged — only the published contract
  was wrong, so no client that was already working needs to change. Two new
  always-on checks close the class: every paginating handler must declare an
  envelope, and no `@action` may publish its viewset's default serializer unless it
  actually returns one (#2583).
