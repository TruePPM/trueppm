The program P80 completion figure now says when it rests on out-of-date forecasts. `GET /programs/{id}/rollup/` carries `projects_with_stale_forecast` and `projects_with_stale_forecast_ids` on `p80_completion` (and `forecast`). They count the forecasts it read that no longer describe their project's plan, using the same rule as the project forecast. Those forecasts stay in the date. The program overview and the PM and Executive homes name them ("1 forecast is out of date (Data Migration); the program P80 still counts it until it is rerun."). The program P50 and P95 now sit beside the P80, by the same rule (the latest of each percentile across the projects' newest forecasts), in `percentiles` on `p80_completion` and `forecast`, each with its own driving project and the projects it leaves out; a forecast with no P95 is named, not filled from an older run. Both overviews show the range, and the v1 card says the percentiles are the latest per project, not a joint forecast.
