The program P80 completion figure now says when it rests on out-of-date forecasts. `GET /programs/{id}/rollup/` carries `projects_with_stale_forecast` and `projects_with_stale_forecast_ids` on `p80_completion` (and `forecast`). They count the forecasts it read that no longer describe their project's plan, using the same rule as the project forecast. Those forecasts stay in the date. The program overview names them ("1 forecast is out of date (Data Migration); the program P80 still counts it until it is rerun."). When nothing is missing or stale, the overview card says the date is the latest project P80, not a joint forecast. ADR-0088 gains the Date reducer row and the staleness policy (#2408, #753).
