- **Project-scoped API token write paths now get a live minter-role recheck, with an org-asset carve-out**: `IsTokenForProject`'s project-scoped branch previously had no live re-check of its minter at all — a minter demoted to Viewer, or removed from the project, kept full write authority through an already-minted project token. The minter's live `ProjectMembership` role is now checked at request time: a minter demoted to Viewer loses write authority on the very next request. A minter *removed* from the project, or whose account is deleted, is not rechecked at all — the token keeps full write authority in both cases, preserving the documented org-asset, survives-off-boarding contract.
