- **mcp Docker image now installs from its checked-in lockfile**: `packages/mcp/Dockerfile` ran `pip install --no-cache-dir /build/mcp`, a fresh resolution against whatever PyPI served on the day of the build — `packages/mcp/uv.lock` was never consulted, so two images built from the same commit on different days could ship different dependency versions (same structural gap as #4078 on the api image). The builder stage now runs `uv export --frozen --no-dev --no-emit-project` and installs the result with `pip install --require-hashes`, then installs the local package with `--no-deps`, and a boot smoke (`import trueppm_mcp.cli`) proves the image can still start before it ships (#4184).
