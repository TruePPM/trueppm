- **Forecast calibration capture (opt-in, per project).** Set `forecast_calibration_capture` on a project (Admin and above; off by default, never inherited) and every baseline, including a replan taken through a baseline decision, records the forecast it carried: the CPM finish for each committed task and the project, each task's duration and three-point estimate at that moment, plus the project's latest Monte Carlo P50/P80/P95. `python manage.py export_forecast_calibration` exports the records of opted-in projects as versioned JSON Lines (`trueppm.forecast-calibration` v1), joined to each task's actual start and finish at export time. No user, name or free text is recorded or exported. This records the data and does not analyze it. See *Administration → Forecast calibration capture* (ADR-1511).
