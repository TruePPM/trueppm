Endpoints that read named fields from a JSON request body now return **400** rather than **500** when the body is a JSON array. A top-level array is a legal JSON body, and `request.data.get(...)` on one raises `AttributeError`, which DRF surfaces as a server error — so the caller was told the server broke rather than that their request was malformed. Thirty reachable call sites are guarded; the `field-values` endpoint is the sharpest case, because its `"value" not in request.data` check passed for a list body before failing on the subscript one line later.
