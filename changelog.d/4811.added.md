Timesheet review (API): a workspace admin sets each person's direct manager (`/api/v1/reporting-lines/`), and that manager approves or returns a submitted week with a required reason (`/api/v1/me/reports/`). An approved week is read-only on every write path, a returned week is editable and resubmittable, and every transition is logged. Time entries gain a `category` (task, PTO, admin, training); only task time counts toward project actual cost. A manager sees a report's submitted, approved and returned weeks only, never a draft. Single-level review only (ADR-1495).
