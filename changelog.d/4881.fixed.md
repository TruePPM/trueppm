Direct-object `schedule()`, `monte_carlo()` and `derive_value()` now refuse `Task.percent_complete=None` with `InvalidScheduleInput`, matching `Task.from_dict`, so a project the scheduler accepts always round-trips through `to_json`/`from_json`. Library consumers passing `percent_complete=None` must pass `0.0` instead; `Task.to_dict()`/`to_json()` now refuse it too (#4881).
