- Operators can set the import, MPXJ, seed-import and time-tracking limits as `TRUEPPM_<NAME>` (for example `TRUEPPM_CSV_IMPORT_MAX_ROWS`). The bare names keep working as deprecated fallbacks and log a one-time warning; they are removed at 1.0. One precedence rule now covers every legacy pair: a non-empty prefixed value wins, an empty one counts as unset.
