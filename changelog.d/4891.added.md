**Driving chain for a task in one call** (`GET /api/v1/projects/{id}/schedule/driving-chain/`, MCP tool `get_schedule_driving_chain`). Returns the chain of driving links through a task — upstream to the anchor, downstream to the project finish — from a single server-side CPM pass, with links on summary tasks already expanded to the leaf edges the engine scheduled. Bounded by `depth` (default 25, max 50) and a 200-node cap with an explicit `truncated` flag; a task the CPM pass does not schedule returns `computable: false` with a reason. The response carries a `_provenance` stamp (engine version, API version, input hash, computed-at) and no assignee, hours, or velocity. Viewer+ and `mcp:read`; shares the `cpm_on_read` throttle with the derivation read (ADR-1381, #4891).
