API tokens, including an Owner's personal access token, can no longer send, resend or delete workspace invites, change or remove workspace members, manage groups and group project grants, transfer workspace ownership, transfer a project's ownership or a program's sponsorship, add or change project and program members, or change a team member's role or facets; a revoked token left those grants behind. They also can no longer create, list or download a workspace export, so automating workspace exports with a token is no longer supported: run the export from a signed-in session or use the database backup path. Reads of invites, groups and memberships remain available to tokens. (#3847)
