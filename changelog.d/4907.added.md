**Near-critical threshold, inheritable workspace → program → project** (`near_critical_threshold_days`, working days, 1–260, default 10). A task whose float is above zero but no more than the threshold is near-critical: the driving-chain response returns it as a per-node `band` (`complete`, `critical`, `near_critical`, `ample`) and echoes the threshold it used. Set it on the workspace, override it per program or project (`effective_*` and `inherited_*` fields show what a scope resolves to). It only shades a display band and never moves a date. The driving-chain payload now spells out the unit of every duration (`{value, unit}`: float in working days, lag in calendar days), carries `schema_version`, `total_links` and `omitted_non_driving_count`, reports `calendar_id` as the effective base calendar, and names the summary a link was expanded from (ADR-1381, #4907).
