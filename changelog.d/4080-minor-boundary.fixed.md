Cutting the first release of a new minor no longer reds `main` at the release commit: `release.sh` keeps the api's `trueppm-scheduler` floor on the published line but widens the ceiling to admit the scheduler being released (so the api image and the published wheel no longer resolve back onto the old line), sets it before `CI_API_TAG` is restamped, and `lint:api-scheduler-lock` tolerates a lock one line behind only on that release commit until the post-publish floor raise lands. `api:wheel-install-probe` now also resolves every `trueppm_scheduler` name the API imports, including imports inside functions.
