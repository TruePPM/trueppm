- **Webhook dispatch now requires Admin+, matching the delivery-log read gate**: a webhook creator demoted to Resource Manager, Team Member, or Viewer — while still a live project member — no longer receives event payloads via dispatch. Previously any live `ProjectMembership` (#4310, #4325) was enough, which let a demoted creator keep receiving full payloads via dispatch after the Admin-only delivery-log endpoint would already refuse them the same data. Applies to both project-scoped and program-scoped webhooks, checked against the registrant's live membership on the firing project. Editing a webhook and reading its delivery log already required Admin and are unaffected by this change. See the upgrade notes for the operator check.
