# Rule 8b — `--sem-*-bg` tokens are for badge pill fills and status cards

> **Invariant.** Indexed from [`packages/web/CLAUDE.md`](../../../packages/web/CLAUDE.md), section *Color and tokens*. The index carries the rule's headline; this file carries its full text (#3744, ADR-0653 amendment). Binding everywhere, not only on the surface that produced it.

**`--sem-*-bg` tokens are for badge pill fills and status cards** — `bg-semantic-critical-bg`, `bg-semantic-at-risk-bg`, `bg-semantic-on-track-bg`, `bg-semantic-warning-bg`. These are pre-computed RGBA values so they cannot be combined with Tailwind's opacity modifier. Always pair with the matching full semantic token for text/border (e.g. `border-semantic-at-risk/80 bg-semantic-at-risk-bg text-semantic-at-risk`). **Never substitute `bg-semantic-{state}/N` (the opacity modifier) for `bg-semantic-{state}-bg`** — `/N` applies Tailwind's alpha to the token's RGB channels, which are **not the `-bg` token's channels**. For `warning` the base is `133 77 14` (#854D0E, the AA-safe *text* color) in light and `250 204 21` (#FACC15, yellow) in dark, while `--sem-warning-bg` is `rgba(217,119,6,…)` (#D97706 brand amber) light and `rgba(251,146,60,…)` (orange) dark: **a different hue in both modes**, not a weaker one — `globals.css` says so itself ("Brand amber #D97706 lives only in `--sem-warning-bg`"). `on-track` diverges the same way in light (`49 111 87` vs `62 140 109`); for `at-risk`/`critical` the RGB matches but the `-bg` alpha is mode-specific against a `/N`'s single fixed alpha. The `-bg` tokens are the only correct form for semantic badge/pill/card fills. A **solid** semantic indicator (a progress/countdown bar) uses the bare token at full strength, not a `/N`; an **interaction wash** (`hover:bg-semantic-critical/5`, `hover:bg-semantic-critical/90`) is legitimate opacity and out of scope. There is no `semantic-success` token — `on-track` is the green; Tailwind emits no CSS at all for an undefined token, so a typo'd semantic class renders as nothing rather than failing. Enforced by `sem_tint_offenders()` in `scripts/check-design-system-v2.sh` (zero tolerance; no check existed before #2858). (Surfaced by ux-review on #691.)
