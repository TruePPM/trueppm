# Rule 214 — Rail tabs, the "More" trigger, and `MoreSheet` nav rows use `focus:ring-*`, not `focus-visible:ring-*`

> **Invariant.** Indexed from [`packages/web/CLAUDE.md`](../../../packages/web/CLAUDE.md), section *Accessibility floors*. The index carries the rule's headline; this file carries its full text (#3744, ADR-0653 amendment). Binding everywhere, not only on the surface that produced it.

**Rail tabs, the "More" trigger, and `MoreSheet` nav rows use `focus:ring-*`, not `focus-visible:ring-*`.** They are standalone tab/menu controls — `focus-visible:` withholds the ring on pointer-driven focus in Firefox/desktop Safari (the ux-review HIGH gate). This is the rule-4/ux-review focus rule applied to the mobile rail; when rebuilding a rail file, convert any pre-existing `focus-visible:` on its controls to `focus:` in the same change rather than carrying it forward. Do NOT reuse the backlog `FOCUS_RING` constant (`features/programs/backlog/styles.ts`) in rail/sheet nav rows — it is `focus-visible:`-based; write `focus:outline-none focus:ring-2 focus:ring-brand-primary focus:ring-inset` inline. Reference: `BottomNav.tsx`, `MoreSheet.tsx`, `bottomNavItems.ts`.
