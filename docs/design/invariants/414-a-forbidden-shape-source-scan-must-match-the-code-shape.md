# Rule 414 — A forbidden-shape source scan must match the code SHAPE, not a bare substring

> **Invariant.** Indexed from [`packages/web/CLAUDE.md`](../../../packages/web/CLAUDE.md), section *Foundations*. The index carries the rule's headline; this file carries its full text (#3744, ADR-0653 amendment). Binding everywhere, not only on the surface that produced it.

**A forbidden-shape source scan — "no module but the owner may declare X" (rule 300's mechanism, `exportCsv.conformance.test.ts`'s shape) — must match the code SHAPE the violation takes, not a bare substring search for the forbidden text.** A substring search over the words alone flags the prose that documents the bug it forbids. Building `lib/healthBand.conformance.test.ts` (#3502) for "no module but `HEALTH_BAND_LABEL` may declare the band words", a plain `/On track/` + `/At risk/` scan flagged `features/shell/HealthCluster.tsx` — the correctly-wired shell chip — because its own docstring quotes `"On track"` and `"At risk"` in prose narrating the #3470 regression the rule exists to prevent, and its `DrillRows` passes `label="At risk"` as an unrelated JSX attribute for a critical-path drill-down section. Neither is the violation; both are a plausible false-flag if the detector cannot tell "restated as a value" from "mentioned". The fix: require the code shape the real offenders share — here, `<key>:\s*['"]On track['"]` (an object-literal value assignment), which a `//` or `/** */` comment does not produce and a JSX `attr="…"` does not either (`=`, not `:`). Two corollaries. **(a) Require co-occurrence, not a single hit** — one incidental match (a field that happens to be titled the same as a band word) is not a private vocabulary; the seven real offenders each restated at least two of the three words together. **(b) Prove the negative case in the test itself** — assert the detector does *not* flag the file whose prose would trip a naive scan, the way `exportCsv.conformance.test.ts` proves non-vacuity by asserting a known offender's *shape*, stripped, now fails. A scan that has never been checked against its own nearest false positive is unverified in the direction that matters most: the direction that would make it useless without ever turning red.
