# Rule 357 — Rule 4's `ring-brand-primary` is measured against an ordinary canvas — on an INVERSE surface it fails, and an …

> **Invariant.** Indexed from [`packages/web/CLAUDE.md`](../../../packages/web/CLAUDE.md), section *Accessibility floors*. The index carries the rule's headline; this file carries its full text (#3744, ADR-0653 amendment). Binding everywhere, not only on the surface that produced it.

**Rule 4's `ring-brand-primary` is measured against an ordinary canvas — on an INVERSE surface it fails, and an alpha modifier on a ring voids the published figure entirely.** Two ways a focus ring silently stops being a focus ring, both invisible to every gate we run. **(a) Wrong ground.** The house ring is sage — `#316F57` light / `#66B998` dark. Against an *inverse* surface (an ink pill, an inverted banner, anything painted `bg-neutral-text-primary`) it measures **2.40:1 light / 2.00:1 dark**, under WCAG 1.4.11's 3:1 *at full alpha*. The fix on such a surface is that surface's own maximum-contrast ink — `ring-neutral-text-inverse`, which is 14.2:1 and 15.0:1 — not a darker sage. Rule 4 is not wrong; it is scoped to the ground it was measured on, and an inverse pop surface is a different ground. **(b) Alpha.** `ring-{token}/N` discards the token's published contrast: the toast's Undo carried `ring-brand-primary/70`, which is 1.82:1 / 1.60:1. Alpha on a *fill* is a tint and costs little; alpha on a *ring* is subtraction from the one thing whose entire job is to be seen. Use the full-alpha token or compute the composite and prove ≥3:1 in both modes **in the same diff**. **(c) Escalate when focus does more than mark position.** A ring is normally a polish finding; when the focused state changes behavior beyond its own element — pausing a timer, blocking a queue, claiming a slot (rule 356(d)) — an invisible ring is a *correctness* defect, because the user is in a mode they cannot see and did not choose. Note the mechanism honestly (rule 300): no gate reads `ring-{token}/N` and none computes a composite against the ancestor's background, so this class is review-only — when you touch a focus ring on a non-default ground, do the arithmetic and put the numbers in a comment. Reference: `components/Toast/ToastHost.tsx` — #3149.
