# Rule 336 — A tinted control inside an already-tinted container composites TWICE — an AA-safe token pair is not AA-safe …

> **Invariant.** Indexed from [`packages/web/CLAUDE.md`](../../../packages/web/CLAUDE.md), section *Placeholders and operator surfaces*. The index carries the rule's headline; this file carries its full text (#3744, ADR-0653 amendment). Binding everywhere, not only on the surface that produced it.

**A tinted control inside an already-tinted container composites TWICE — an AA-safe token pair is not AA-safe at nesting depth 2, and the DS-v2 gate's own prescribed fix does not rescue it.** Every `semantic-*` and `brand-primary` contrast figure in this file and in `globals.css` is measured against an **opaque** surface. Put a `bg-{token}/N` or `bg-{token}-bg` control *inside* a banner or card whose own background is a tint of the same hue and the two alphas stack: the foreground barely moves while the background travels toward it, and the pair drops below 4.5:1. Measured on `SprintCloseFailedBanner` over `bg-app-canvas` (**not** white — that is the surface anything under `SprintsView` actually composites onto): `text-semantic-critical` on `bg-semantic-critical/10` inside `bg-semantic-critical-bg` is **4.21:1 light / 3.58:1 on hover**, and swapping to `bg-semantic-critical-bg` — the substitution rule 8b prescribes — is only **4.34:1 light / 4.21:1 dark, still failing**. So: **an action button inside a tinted banner takes either no fill at all (border + text, hover wash on an opaque token) or an opaque `bg-neutral-surface` base** — 4.91:1/5.33:1 and 6.47:1/5.73:1 respectively. Two things this rule exists to say that no gate can. **(a) A green DS-v2 run is not evidence about nesting.** `sem_tint_offenders()` in `scripts/check-design-system-v2.sh` matches the `semantic-*` families only, so the identical `brand-primary` failure in the sibling `RetroHandoffBanner` (`text-brand-primary` on `bg-brand-primary/10` inside `bg-brand-primary/5`, **4.23:1 light**) is invisible to it — the gate caught this file and cannot catch that one. **(b) Compute contrast against the surface the element actually composites onto**, walking up to the nearest **opaque** ancestor, not against white and not against the immediate tinted parent alone. This is rule 300 applied to contrast: the reason the class recurs is that the arithmetic everyone does is one layer shallower than the DOM. Reference: `features/sprints/SprintCloseFailedBanner.tsx`, `features/sprints/RetroHandoffBanner.tsx` — #2992.
