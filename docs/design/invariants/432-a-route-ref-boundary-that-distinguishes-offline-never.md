# Rule 432 — A route/ref boundary that distinguishes "offline, never resolved" from "not found" must render each through its own copy

> **Invariant.** Indexed from [`packages/web/CLAUDE.md`](../../../packages/web/CLAUDE.md), section *Surface states*. The index carries the rule's headline; this file carries its full text (#3744, ADR-0653 amendment). Binding everywhere, not only on the surface that produced it.

**A route/ref boundary that distinguishes "offline, never resolved" from "not found" must render each through its own copy — collapsing both onto one 404 component tells a merely-offline visitor their link is broken.** `ProgramRefBoundary` computed the distinction (`route.status === 'offline'` is a real, separately-tracked state, not a fallback) and then threw it away — `route.status === 'not-found' || route.status === 'offline'` fed both into the same `<NotFoundPage />` with no body override, so a program key URL opened offline before this device had ever resolved it read exactly like a deleted or inaccessible program. `ProjectRefBoundary` already got this right: its `offline` branch renders `ProjectNotFound` with `PROJECT_LINK_NEEDS_CONNECTION`, a body that says the honest thing — there is no way to know what the link points at without a connection — rather than asserting a cause (deleted, no access) the client cannot know. `NotFoundPage` gained the same `body` override so `ProgramRefBoundary` could do the same thing with `PROGRAM_LINK_NEEDS_CONNECTION`, without inventing a second not-found component. The general shape: once a boundary has *computed* two distinct terminal states, every render branch must reach a visibly distinct outcome — a shared `if (a || b) return <SameThing />` is where the distinction quietly dies, usually because the second state was added after the component already had a not-found path and the fastest fix was to fold it in. Reference: `packages/web/src/router/RefBoundary.tsx` (`ProjectRefBoundary` / `ProgramRefBoundary`), `packages/web/src/components/NotFoundPage.tsx`, `packages/web/src/features/project/ProjectNotFound.tsx` — ADR-1237 §7, #4148.
