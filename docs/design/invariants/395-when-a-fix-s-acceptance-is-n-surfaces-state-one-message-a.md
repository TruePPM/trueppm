# Rule 395 — When a fix's acceptance is "N surfaces state one message", a source scan for the canonical LITERAL cannot …

> **Invariant.** Indexed from [`packages/web/CLAUDE.md`](../../../packages/web/CLAUDE.md), section *Foundations*. The index carries the rule's headline; this file carries its full text (#3744, ADR-0653 amendment). Binding everywhere, not only on the surface that produced it.

**When a fix's acceptance is "N surfaces state one message", a source scan for the canonical LITERAL cannot enforce it — the scan sees re-typing, and re-typing is never the failure mode; divergence is.** A shared constant plus a scan over `src/` for its string is green in exactly the case the fix was written to prevent: a surface saying the same thing in *different words*. #3472 extracted the ADR-0104 velocity-privacy sentence and pinned it with such a scan; four sibling surfaces state the same verdict in four other wordings and the scan passes over every one of them. Three obligations. **(a) Prefer extracting the RENDERING over the string** — one shared component (icon, tone, testid, sentence) parameterised by subject means a divergent wording is a missing import rather than an invisible pass. **(b) Where a scan is kept, gate the POPULATION, not the literal**: enumerate the surfaces in the family and assert each mounts the shared component — a message family always has more members than the two an issue names. **(c) A docstring claiming more than the assertion holds is rule 300's named defect in miniature** — prose and gate are two artifacts, and the gate's green is not evidence about the prose. Write what the mechanism *cannot* see into the mechanism, and name the known survivors so the next reader can check the claim rather than trust it. Reference: `features/sprints/VelocityTeamPrivateNote.test.tsx` (the scan and its stated blind spot), `features/sprints/MultiTeamLens.tsx`, `features/shell/healthClusterModel.ts`, `features/sprints/MilestoneBridgeForecast.tsx` (the survivors) — #3472, surfaced by `ux-review`; the population gate for this family is **#3507**. **Do not write "tracked" into a rule or a docstring without the issue number in the same edit** — a false "tracked" in `packages/web/CLAUDE.md` is permanent and unfalsifiable, and this rule's own first draft carried one.
