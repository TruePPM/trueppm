# Rule 296 — A truncation notice ships with a way past the cap, on the same surface

> **Invariant.** Indexed from [`packages/web/CLAUDE.md`](../../../packages/web/CLAUDE.md), section *Dialogs, focus and keyboard*. The index carries the rule's headline; this file carries its full text (#3744, ADR-0653 amendment). Binding everywhere, not only on the surface that produced it.

**A truncation notice ships with a way past the cap, on the same surface.** "and N more", "showing the first 12", "top 8" is an honest label and an incomplete affordance: it tells the user the thing they want may be unreachable and then does not hand them a route to it. Every surface that caps a list carries its escape hatch — expand, paginate, or export — *on that surface*, not only on a later step that happens to render the same component. The trap is a shared component whose escape hatch is an optional prop: it gets wired at the site where the reviewer noticed the cap and silently omitted everywhere else, so the cap is honest in one place and a dead end in another. Where the surface is a pre-commit confirmation, the rule is strongest — that is the screen where the decision is made. Reference: `components/import/CsvImportWizard.tsx` (`RowIssueList`'s `onDownload`, wired on both the confirm and result steps).
