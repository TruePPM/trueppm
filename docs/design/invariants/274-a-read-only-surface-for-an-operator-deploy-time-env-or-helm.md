# Rule 274 — A read-only surface for an operator / deploy-time (env or Helm) value presents an honest *status* — a state …

> **Invariant.** Indexed from [`packages/web/CLAUDE.md`](../../../packages/web/CLAUDE.md), section *Placeholders and operator surfaces*. The index carries the rule's headline; this file carries its full text (#3744, ADR-0653 amendment). Binding everywhere, not only on the surface that produced it.

**A read-only surface for an operator / deploy-time (env or Helm) value presents an honest *status* — a state chip, the controlling env-var name, and an explicit "configured in the server environment, not editable here" — never a disabled in-app toggle or a "fix it here" link.** Such values are set outside the app (env / Helm `values.yaml`) and no authenticated user may change them through the UI — that boundary is deliberate (e.g. a platform DoS protection must not be app-toggleable). Show the live state read-only and name the lever the operator actually uses; a dead toggle, or a link that goes nowhere, is worse than plain text. This is the operator-status corollary of the rule-8 live-wiring discipline ("hide a not-yet-wired control; never present a dead control as if it works"). Reference: `RateLimitDisabledBanner.tsx` + the `RateLimitCard` in `features/settings/workspace/SystemSummaryCards.tsx` (the `TRUEPPM_RATE_LIMIT_ENABLED` kill-switch status, #2316 / ADR-0604), mirroring the read-only OTel telemetry posture card.
