# Rule 404 — A "this surface does not apply to you" disclosure must be gated on the CONDITION, never on emptiness — an …

> **Invariant.** Indexed from [`packages/web/CLAUDE.md`](../../../packages/web/CLAUDE.md), section *Product boundary*. The index carries the rule's headline; this file carries its full text (#3744, ADR-0653 amendment). Binding everywhere, not only on the surface that produced it.

**A "this surface does not apply to you" disclosure must be gated on the CONDITION, never on emptiness — an explanation that lives only inside the empty state is blind to the populated case, which is the worse one.** #2619 shipped `MethodologyEmptyState` on six surfaces to explain why a methodology-hidden view (reachable by direct URL on purpose) is not part of the project's workflow. Every one of those call sites fired only under `length === 0`. So the state the explanation existed *for* — an AGILE flip on a project with a real CPM schedule, a WATERFALL flip on a groomed backlog — rendered the ordinary populated view with **no signal on either path**, and the work sat reachable by URL alone with nothing naming it. Four of five audit personas found this independently; the empty half had shipped four months earlier and read as done. **The tell is structural and greppable: a conditional whose two operands are a domain predicate and a `length === 0`/`isEmpty`/`allEmpty`.** Emptiness is a *rendering* branch; the predicate is the *fact*. Folding them makes the fact deniable exactly when there is something at stake, because data existing is what makes the mismatch matter. **The fix shape is two disjoint, exhaustive branches over the same predicate** — `predicate && count === 0` → the explanatory empty state (calm `EmptyState` anatomy, rule 177), `predicate && count > 0` → a standing disclosure over the real content (`semantic-at-risk`, not `QueryErrorState`: the data and the configuration disagree, nothing failed). Three constraints on the populated half. **(a) It is not dismissible.** It states a standing truth, not an event, and removes itself when either half stops holding; a dismiss control teaches the reader to clear it and restores the silence. Contrast the dismissible neighbors (`CapacityWarningsAlert`, the backlog conflict notice), which report a moment. **(b) Where the surface has a filter, gate and count on the UNFILTERED set** (rule 388) — this is a statement about the project, not about the active filter, and a filter hiding every row would otherwise silence it. Where two surfaces show the same fact through different denominators (`ScheduleView`'s filtered `visibleTasks` vs `CalendarView`'s dated set), drop the count rather than print two numbers for one fact. **(c) Rule 392 still applies to both halves** — `0` while a query is in flight or after it failed is "unknown", never "the condition does not hold". **And cover the populated case in the test beside the empty one**, or the next reader sees a passing empty-state spec and concludes the class is handled. Reference: `features/shell/MethodologyMismatchBanner.tsx` + `MethodologyEmptyState.tsx`, six call sites each — #2619.
