# Rule 423 — A Recharts root inside an `aria-hidden` wrapper must set `accessibilityLayer={false}`

> **Invariant.** Indexed from [`packages/web/CLAUDE.md`](../../../packages/web/CLAUDE.md), section *Accessibility floors*. The index carries the rule's headline; this file carries its full text (#3482). Binding everywhere, not only on the surface that produced it.

**Every chart's SVG in this codebase is `aria-hidden` with an `sr-only` text summary as the real accessible read (issue 2175) — but Recharts 3.x's `accessibilityLayer` (default `true` on every chart root: `AreaChart`, `BarChart`, `ComposedChart`, `LineChart`, …) injects its own focusable keyboard-navigation overlay into the SVG regardless.** An `aria-hidden` ancestor does not stop that overlay from receiving focus — it only removes it from the accessibility tree — so the result is a focusable element a sighted keyboard user can tab into and see nothing happen (or worse, a screen-reader user's focus lands somewhere the AT never announces): axe `aria-hidden-focus`, serious, WCAG 2.1 A 4.1.2. This hit four routes in one sweep (Overview, Board, Sprints, Reports) because they all render `BurnChart`/`CompactBurnChart` or `FlowAnalyticsPanel`'s charts (#3482).

**Pass `accessibilityLayer={false}` on every Recharts chart-root component you place inside an `aria-hidden` wrapper** (`BurnChartCanvas.tsx`, `CompactBurnChart.tsx`, `FlowAnalyticsPanel.tsx`). This removes the overlay entirely rather than trying to neutralize a focusable node after the fact (there is no supported way to make the injected overlay `tabindex="-1"` from the outside). It is a no-op visually and functionally for a chart that is already `aria-hidden` — the keyboard-navigation feature the layer exists for is for a chart that *is* the accessible surface, which is not this codebase's pattern (the `sr-only` summary is). If a future chart is added as the primary accessible surface (not `aria-hidden`), `accessibilityLayer` should stay on and be evaluated on its own; this rule applies specifically to a Recharts root that shares a subtree with an `aria-hidden` ancestor.
