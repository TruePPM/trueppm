# Rule 248 — A data surface's loading state is a skeleton ghost that mirrors the shape of the real content, never a bare …

> **Invariant.** Indexed from [`packages/web/CLAUDE.md`](../../../packages/web/CLAUDE.md), section *Surface states*. The index carries the rule's headline; this file carries its full text (#3744, ADR-0653 amendment). Binding everywhere, not only on the surface that produced it.

**A data surface's loading state is a skeleton ghost that mirrors the shape of the real content, never a bare `Loading…` text line.** Every primary surface (Schedule, Grid, My Work, Overview, Reports, Today, and — since #1774 — Board, Sprints, and the project Backlog) renders pulsing placeholder blocks while its query is in flight, so the layout doesn't jump when data lands. The idiom: one `role="status"` wrapper with an `aria-label="Loading X…"` accessible name (the E2E wait-for-paint gate resolves on this node detaching — gate specs on `getByRole('status', { name: /Loading X/i })`, not on a visible text string), and every ghost child is a `motion-safe:animate-pulse rounded-* bg-neutral-surface-sunken` block marked `aria-hidden="true"`. Mirror the surface's real shape — column ghosts for the Board (a row of lane placeholders), row ghosts for list/table surfaces (Backlog, Grid), card ghosts for card lists (Sprints). `motion-safe:` is mandatory so the pulse honors `prefers-reduced-motion`. Never gate an E2E on the *absence* of a visible "Loading…" string (it reads count-0 before the surface even mounts, racing the assertion); gate on the skeleton's `role="status"` node detaching, which is the true "loading finished" signal. **The rule covers chunk-loading as well as query-loading (#2431).** The route-level `Suspense` fallback is the *first frame of every navigation* — the single most-seen loading state in the app — and it used to be the one place that rendered the bare centred `Loading…` this rule forbids, so a Board navigation opened on ~3s of unstyled text before the (compliant) board skeleton appeared. Both loading states that have no surface shape of their own take the shared `components/LoadingSkeleton.tsx` instead of hand-rolling one: the Suspense fallback and the `/` root-redirect hold use `variant="shell"` (toolbar band + content rows — deliberately generic, because which surface is arriving is exactly what an unresolved chunk does not know), and in-page settings sections use the default `variant="rows"`. **The settings density exception covers ghost *size*, not the skeleton contract** — a settings section still ghosts, just more compactly. Reach for a surface-specific skeleton only when the real content has a distinctive shape worth mirroring. Reference: `components/LoadingSkeleton.tsx`, `router.tsx`, `features/board/BoardView.tsx`, `features/sprints/SprintsView.tsx`, `features/project/backlog/ProductBacklogPage.tsx`, `features/grid/GridView.tsx`.
