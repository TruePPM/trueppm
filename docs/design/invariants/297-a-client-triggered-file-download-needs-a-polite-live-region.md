# Rule 297 — A client-triggered file download needs a polite live-region confirmation

> **Invariant.** Indexed from [`packages/web/CLAUDE.md`](../../../packages/web/CLAUDE.md), section *Dialogs, focus and keyboard*. The index carries the rule's headline; this file carries its full text (#3744, ADR-0653 amendment). Binding everywhere, not only on the surface that produced it.

**A client-triggered file download needs a polite live-region confirmation.** A download is the one user-initiated action that produces *no* in-page change, so without an announcement it is indistinguishable from a dead button for screen-reader and low-vision users (WCAG 4.1.3). Mount the region **unconditionally** and set its text on success — a live region created in the same tick as its content does not reliably announce, which is why the reference implementation renders an empty `sr-only` span up front rather than conditionally rendering the whole node. The pattern was already in the tree when a second download button was added to the same file without it, which is the reason it is written down. **Use `hooks/useDownloadAnnouncer.tsx`** — it owns the region and returns it already-rendered, so the announcement rides with the helper instead of being something each caller remembers; `download(csv, filename, message)` wraps `downloadCsv`, and `announce(message)` is for a caller whose own helper owns the filename (`exportRisksToCSV` stamps the local calendar day). This is a rule 300 case: the rule was written down after a second download button appeared in a file that already had the pattern, and three more sites then shipped without one (#2943) — so the mechanism, not the sweep, is the fix. `utils/exportCsv.conformance.test.ts` now fails a component that can reach a download and mounts no region, and it **derives** the trigger set from source (`downloadCsv` plus the exported wrappers around it) rather than enumerating sites: `RiskRegisterHeader` reaches a download one hop away through `exportRisksToCSV`, and a check keyed on `import { downloadCsv }` would have called it clean. Reference: `components/import/CsvImportWizard.tsx` (`UploadStep`'s "Template downloaded." span, `RowIssueList`'s "Problem rows downloaded.").
