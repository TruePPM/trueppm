# Rule 244 — A `<canvas>` is not touched by the forced-colors (Windows High Contrast) user-agent transform, so …

> **Invariant.** Indexed from [`packages/web/CLAUDE.md`](../../../packages/web/CLAUDE.md), section *Canvas*. The index carries the rule's headline; this file carries its full text (#3744, ADR-0653 amendment). Binding everywhere, not only on the surface that produced it.

**A `<canvas>` is not touched by the forced-colors (Windows High Contrast) user-agent transform, so canvas-drawn UI must detect `(forced-colors: active)` and repaint with CSS *system-color* keywords — otherwise it renders its fixed colors into a high-contrast theme and becomes invisible/unreadable.** DOM chrome gets forced-colors for free (the UA remaps `color`/`background`/`border` to the theme); pixels a component draws into a canvas do not. The Gantt engine (`GanttEngineImpl`) subscribes to `window.matchMedia('(forced-colors: active)')` (mirroring the `prefers-reduced-motion` pattern — detect at init, re-detect on `change`, full-repaint on flip, unsubscribe in `destroy`) and passes the flag to `setRendererColorMode(dark, forced)`, which selects a third palette `COLOR_FORCED` built entirely from system-color keywords the 2D context resolves against the active theme: `Canvas`/`CanvasText` (surface/ink), `GrayText` (de-emphasis), `Highlight` (accent + selection), `LinkText` (links). Because the system palette is intentionally flat, **bar *kinds* must not depend on hue** in this mode — lean on shape (milestone diamond, summary endcaps) and the `Highlight` accent for critical/selection (color is never the sole differentiator, rule 6). Semi-transparent tints (row banding, weekend shading, ghost fills) collapse to the solid surface/ink so nothing relies on alpha the theme may not honor. Keep the palette-selection function (`pickPalette(dark, forced)`) pure and exported so it is unit-testable without a canvas, and assert that a draw pass in forced mode emits system-color `fillStyle`s (not brand hex). Forced-colors wins over dark/light — it is a hard accessibility preference, not a cosmetic mode. Reference: `COLOR_FORCED` / `pickPalette` / `setRendererColorMode` in `engine/GanttRenderer.ts`, the `_forcedColors` wiring in `engine/GanttEngineImpl.ts`.
