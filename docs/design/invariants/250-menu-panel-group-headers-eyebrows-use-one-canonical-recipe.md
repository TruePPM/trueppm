# Rule 250 — Menu/panel group headers (eyebrows) use one canonical recipe: `text-xs font-semibold uppercase …

> **Invariant.** Indexed from [`packages/web/CLAUDE.md`](../../../packages/web/CLAUDE.md), section *Controls and composition*. The index carries the rule's headline; this file carries its full text (#3744, ADR-0653 amendment). Binding everywhere, not only on the surface that produced it.

**Menu/panel group headers (eyebrows) use one canonical recipe: `text-xs font-semibold uppercase tracking-[.06em] text-neutral-text-secondary`; inside a `role="menu"` or dialog, wrap the grouped rows in a `role="group"` labeled "like the header" (`aria-label` or `aria-labelledby`), with the visible header div `aria-hidden`.** The tree had grown ≥4 competing eyebrow treatments (`text-[11px] tracking-[.08em]`, `text-[11px] tracking-wide`, `tracking-widest`, …); `text-xs` is the rule-50 floor, so it is the canonical size — do not mint new size/tracking combos. `role="group"` is a permitted owned element of `role="menu"` and is transparent to `useFocusTrap` (descendant selector) and to Escape/outside-click handling. Reference: `features/shell/UserMenu.tsx` ("Personal" group).
