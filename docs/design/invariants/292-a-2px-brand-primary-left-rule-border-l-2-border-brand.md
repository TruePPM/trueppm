# Rule 292 — A 2px brand-primary left rule (`border-l-2 border-brand-primary`) is this app's SELECTION/ACTIVE idiom — a …

> **Invariant.** Indexed from [`packages/web/CLAUDE.md`](../../../packages/web/CLAUDE.md), section *Iconography*. The index carries the rule's headline; this file carries its full text (#3744, ADR-0653 amendment). Binding everywhere, not only on the surface that produced it.

**A 2px brand-primary left rule (`border-l-2 border-brand-primary`) is this app's SELECTION/ACTIVE idiom — a static informational block uses `border-l-4`.** The 2px form means "the thing you selected / the page you are on" everywhere it appears: `Sidebar.tsx` (active nav), `SettingsShell.tsx` (the active scroll-spy rail item), `TaskListRow`, `BoardView`, `RosterList`, `TaskRow`, `columnHeaderParts`. Reusing it for a non-interactive note inside `features/settings/` is the worst case, because the shell's active rail item renders the identical treatment **in the same viewport** — two identical marks, same screen, different meanings, and a user who has learned the idiom gets a false positive on a static paragraph. The informational form is `border-l-4 border-brand-primary pl-3` (reference: `WebhookEditorModal.tsx`, `StakeholderReachSummary.tsx`), which also happens to align the block's text edge with a sibling `px-4` table header. If the block is not brand-relevant at all, use a neutral or semantic border instead. Surfaced by the #2529 ux-review.
