# Rule 273 — `AppShell` renders the single `<main id="main-content">` landmark — a feature page, panel, or state-branch …

> **Invariant.** Indexed from [`packages/web/CLAUDE.md`](../../../packages/web/CLAUDE.md), section *Controls and composition*. The index carries the rule's headline; this file carries its full text (#3744, ADR-0653 amendment). Binding everywhere, not only on the surface that produced it.

**`AppShell` renders the single `<main id="main-content">` landmark — a feature page, panel, or state-branch (loading/error/empty) rendered inside the shell must NOT emit its own `<main>`; use a labeled `<section aria-label>` (or a `<div>` when it already owns a `role`).** The skip-link (`#main-content`) and "jump to main content" both target AppShell's one main; a second `<main>` nested inside it is invalid HTML and makes the SR "jump to main" ambiguous. This recurs at the page root and, easy to miss, in early-return branches (a page with a `<main aria-busy>` loading state, a `<main role="alert">` error state, and a `<main aria-label>` success state is **three** nested mains, not one). The batch that established this rule demoted five pages / eight tags (`MyWorkPage`, `SprintsView` ×2, `PersonalAccessTokensPage`, `MyGeneralPreferencesPage`, `ConnectedAccountsPage` ×3). Grep before adding any page-level wrapper: `grep -rn "<main" packages/web/src/features/` — the only legitimate matches are `AppShell.tsx` (the shell's one main) and the standalone **public share pages** (`PublicScheduleSharePage`, `PublicBoardSharePage`), which render *outside* AppShell (no auth, no shell) and therefore own their page's sole `<main>`. Keep the element's existing `aria-label`/`aria-busy`/`role` when demoting (`<main aria-label="X">` → `<section aria-label="X">`; `<main role="alert">` → `<div role="alert">`). Corollary — the authed catch-all 404 renders **inside** AppShell (`path: '*'` as a child of the `/` AppShell route), not as a shell-less sibling, so an unknown URL keeps the sidebar, TopBar, and ⌘K palette; the `NotFoundPage` reuses the `RouteErrorBoundary` anatomy (`role="alert"`, `tabIndex={-1}` heading self-focused on mount per rule 224, `focus:` not `focus-visible:`) and offers client-side "Go to My Work" / "Go to home" recovery — never a dead-end with nothing focusable. Reference: `components/NotFoundPage.tsx`, `features/shell/AppShell.tsx`, `router.tsx` (dual `path: '*'`).
