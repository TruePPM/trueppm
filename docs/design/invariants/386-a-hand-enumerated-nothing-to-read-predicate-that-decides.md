# Rule 386 — A hand-enumerated "nothing to read" predicate that decides FOCUS SEATING rots the moment a new conditional …

> **Invariant.** Indexed from [`packages/web/CLAUDE.md`](../../../packages/web/CLAUDE.md), section *Surface states*. The index carries the rule's headline; this file carries its full text (#3744, ADR-0653 amendment). Binding everywhere, not only on the surface that produced it.

**A hand-enumerated "nothing to read" predicate that decides FOCUS SEATING rots the moment a new conditional paragraph lands beside it — re-derive it, or put the content inside the live region.** `CsvImportWizard`'s `cleanSuccess` lists the result step's readable blocks by name — notices, parked rows, row errors — to decide whether focus goes to the primary CTA or to Close, and its own docstring commits to "nobody is walked past a report on their way out" (rule 288 §5.8). #3353 added a fourth conditional paragraph, the undo-floor disclosure, and the predicate did not move — so the one reader that paragraph exists for was the one focus jumped past, and because it sits OUTSIDE the `aria-live` outcome sentence it was not announced either. Two negatives that cancel into silence: no focus, no announcement, no symptom in any test. The predicate is not a summary of the surface; it is a **whitelist that stays true only while somebody maintains it**, and nothing in `tsc`, lint or the existing specs notices when it stops. **(a) Any new conditional block on a step whose focus seating is derived from a content predicate joins that predicate in the SAME commit, and the spec that pins seating gains a case for the new state — plus its negative control**, the same state with the block absent, or a `cleanSuccess` that had become permanently false would still pass. **(b) Prefer folding a one-sentence disclosure INTO the surface's existing `aria-live` region over adding a sibling paragraph.** `PasteReceiptStrip` carries the identical sentence from the identical change with no defect, because its note is inside the strip's own `role="status"` and there is no seating decision to keep in sync. Reference: `components/import/CsvImportWizard.tsx` (`cleanSuccess`, `discloseUndoFloor` — derived in the parent for exactly this reason), `features/schedule/buildMode/pasteMany/PasteReceiptStrip.tsx` — #3353, surfaced by `ux-review`.
