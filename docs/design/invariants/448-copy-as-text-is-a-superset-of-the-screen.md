# Rule 448 — Copy as text is a superset of the screen

> **Invariant.** Indexed from [`packages/web/CLAUDE.md`](../../../packages/web/CLAUDE.md), section *Redundancy*. The index carries the rule's headline; this file carries its full text (#4892). Binding on every surface it names.

Copy as text is a superset of the screen: anything shown visually (color, dash, indent) also exists as words in the copied text and the accessible name, and a vitest asserts every rendered node name and edge label is in the text output (#4892).

**Origin.** Written with the Schedule drawer's "Why critical" section (#4892), whose design (ux-design, 2026-11-14) surfaced it. It applies to any later surface of the same shape, not only that one.
