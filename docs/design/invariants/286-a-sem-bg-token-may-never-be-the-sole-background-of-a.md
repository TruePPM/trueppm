# Rule 286 — A `--sem-*-bg` token may never be the sole background of a floating surface — a portaled, `position:fixed` or …

> **Invariant.** Indexed from [`packages/web/CLAUDE.md`](../../../packages/web/CLAUDE.md), section *Color and tokens*. The index carries the rule's headline; this file carries its full text (#3744, ADR-0653 amendment). Binding everywhere, not only on the surface that produced it.

**A `--sem-*-bg` token may never be the sole background of a floating surface — a portaled, `position:fixed` or `absolute` panel needs an opaque base (`bg-neutral-surface`), with its warning/error tone carried by the border, icon and text (#2447).** The `-bg` family is 8–15% alpha (`--sem-at-risk-bg: rgba(146,64,14,0.10)` light / `rgba(251,146,60,0.15)` dark), which rule 8b already scopes to **badge pill fills and status cards** — surfaces that sit on an opaque parent, where the alpha composites over a known background. A floating surface has no such parent: it composites over whatever page content it happens to overhang, so the rows, digits and chips behind it read straight through the copy. This is not a dark-mode bug — light mode is *worse*, because its alpha is lower (10% vs 15%), so the popover body ends up ~90% transparent over the task list. Two invariants: (a) **the opaque base is `bg-neutral-surface`, not a hand-composited hex** — a pre-multiplied "amber over white" token would bake in an assumption about which surface the panel floats over, and a portaled panel does not know; (b) **the semantic tone survives the swap** because it was never carried by the fill alone — the border (`border-semantic-at-risk`), the `WarningIcon` and the heading/body colour all remain, which is also what keeps colour off the sole-signal path (rule 6). `ScheduleCommitPopover` (`bg-neutral-surface border border-neutral-border`) is the reference every pop surface should already have matched. The trigger *chip* keeps `bg-semantic-at-risk-bg` — an in-flow element on an opaque row is exactly rule 8b's sanctioned use, and only the floating panel changes. Reference: `features/schedule/MissingCommittedStartChip.tsx`, `features/timesheet/TimesheetCell.tsx`.
