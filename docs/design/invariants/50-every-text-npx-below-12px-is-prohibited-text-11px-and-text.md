# Rule 50 — Every `text-[Npx]` below 12px is prohibited — `text-[11px]` and `text-[10.5px]` included

> **Invariant.** Indexed from [`packages/web/CLAUDE.md`](../../../packages/web/CLAUDE.md), section *Accessibility floors*. The index carries the rule's headline; this file carries its full text (#3744, ADR-0653 amendment). Binding everywhere, not only on the surface that produced it.

**Every `text-[Npx]` below 12px is prohibited — `text-[11px]` and `text-[10.5px]` included.** The design system floor is `text-xs` (12px); arbitrary size values below it bypass the token ladder and introduce WCAG 1.4.3 failures on any surface. **One** exception is left, and it is a named tree rather than a judgement call: `text-[10px]`–`text-[11px]` under `features/settings/` (rule 118's compact-admin density), fractions included, so `text-[10.5px]` is sanctioned there and `text-[9.5px]` is not — the settings floor is a value, not a leading digit. `text-[9px]` and below are prohibited everywhere, settings included. **The StatusBar's `text-[11px]` carve-out is retired (#3475)** — it bought one pixel of chrome quietness on the app's most persistent surface and cost a 1.4.4 risk; the bar is `text-xs` in `h-6`, which fits, and a `text-[11px]` reappearing there is a regression, not a re-grant. **`aria-hidden` does not license sub-floor type on text a sighted user reads** — the two survivors this rule baselined for three releases were exactly that argument (TaskSummaryStrip's 10px owner initials, ProgramIdentitySquare's 7px `xs-label` code), and both are gone: the strip's avatar grew to 24px and took `text-xs`, and the `xs-label` variant was deleted outright once it was checked that **both** of its call sites already render the program name as adjacent text. Two corollaries that cost two extra sweeps to learn. **(a) A size that cannot hold legible type carries none** — the fix for "the glyphs don't fit" is to drop the glyphs and lean on the adjacent label, never to shrink the type; if nothing adjacent carries the meaning, the tile is the wrong container. **(b) The gate is blind to what is not a class.** `tiny_text_offenders()` in `scripts/check-design-system-v2.sh` matches `text-[Npx]` and nothing else, so an inline `style={{ fontSize: 10 }}` or a derived one (`fontSize: size * 0.42`) passes it silently — the baseline is 0 and stays 0, which makes the number meaningful only for the class-shaped half. Prefer the Tailwind class so the gate can see it. The pattern has been widened twice against its own blind spots (`text-[11px]` at #2858, decimals at #3475) — see rule 300.
