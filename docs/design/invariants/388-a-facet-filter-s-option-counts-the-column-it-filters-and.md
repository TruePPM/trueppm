# Rule 388 — A facet filter's option counts, the column it filters, and any tally rendered beside it must all be computed …

> **Invariant.** Indexed from [`packages/web/CLAUDE.md`](../../../packages/web/CLAUDE.md), section *Placeholders and operator surfaces*. The index carries the rule's headline; this file carries its full text (#3744, ADR-0653 amendment). Binding everywhere, not only on the surface that produced it.

**A facet filter's option counts, the column it filters, and any tally rendered beside it must all be computed from the same field over the same denominator — a filter that describes a set the surface is not showing is worse than no filter.** A facet control is a claim about the rows behind it, and the claim is checkable by eye: the user clicks `Waterfall 0` and then looks at the screen. Two ways it goes wrong, and both shipped in one change (#3295). **(a) Different field.** The facets bucket on the column's *default* value while the cell has a conditional branch rendering a *different* one — normally identical, so it passes every demo, and divergent in exactly the state the column exists for. On the program Projects matrix the facets bucketed on `effectiveMethodology` while a deviating cell prints the row's own stored value; under a workspace `inherit` lock `effectiveMethodology` is the workspace's on *every* row, so all rows collapse into one facet and `Waterfall 0` renders `aria-disabled` above twelve visible cells reading `Waterfall ≠ workspace (Hybrid)`. Route the facet buckets, the filter predicate, and the cell through **one** function that returns what the cell prints — or suppress the facets entirely in the state that diverges, because a facet that cannot be right is not worth being present. **(b) Different denominator.** A per-column tally computed over the *filtered* rows sits beside a facet count computed over *all* rows, both using the same word: header `Methodology · 5 differ` next to chip `Deviates from default, 12`. Neither number is wrong, neither states its denominator, and the pair reads as a defect. Pick one denominator for a given fact and hold it everywhere that fact is printed (`BulkFieldsMatrix`'s `tallyRows` prop is the shape: the mount passes the unnarrowed set explicitly); where a surface genuinely needs both, the narrowed one names its own scope in its own label (`5 of the 20 shown`) and never leans on a scope note elsewhere on the page to reconcile it. This is rule 323's sibling — 323 covers a *predicate* silently rebased onto a subset, this covers a *displayed count* — and unlike 323's, this failure is visible on screen to the user, which is why it must never ship. Reference: `features/settings/program/ProgramProjectsPage.tsx` (`displayed()`), `features/settings/components/BulkFieldsMatrix.tsx` (`tallyRows`) — #3295.
