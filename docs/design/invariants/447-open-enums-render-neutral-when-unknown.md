# Rule 447 — Open enums render neutral when unknown

> **Invariant.** Indexed from [`packages/web/CLAUDE.md`](../../../packages/web/CLAUDE.md), section *Signal encoding*. The index carries the rule's headline; this file carries its full text (#4892). Binding on every surface it names.

Open enums render neutral when unknown: an unrecognized `band` (or similar) gets the neutral gray treatment and no band word. It never falls through to the critical style and never throws (#4892).

**Origin.** Written with the Schedule drawer's "Why critical" section (#4892), whose design (ux-design, 2026-11-14) surfaced it. It applies to any later surface of the same shape, not only that one.
