# Rule 307 — A global keyboard shortcut that DESTROYS something needs a single arbiter, and the claim registry in …

> **Invariant.** Indexed from [`packages/web/CLAUDE.md`](../../../packages/web/CLAUDE.md), section *Dialogs, focus and keyboard*. The index carries the rule's headline; this file carries its full text (#3744, ADR-0653 amendment). Binding everywhere, not only on the surface that produced it.

**A global keyboard shortcut that DESTROYS something needs a single arbiter, and the claim registry in `hooks/useGlobalShortcut.ts` is that arbiter — do not build a second mechanism.** The failure this prevents is not a duplicate-handler bug, and reading it as one is why it ships: there is no broken handler to find. Three surfaces bound `⌘Z` to their own undo — `ScheduleView`'s paste-many receipt, `SeedBanner`'s template-apply banner, and `CsvImportWizard`'s import result — and **each was individually correct**, each guarded its own preconditions, each had passing tests. They are independently mountable siblings on one route, so the moment two were up at once a single keypress ran two destructive undos: the CSV import reverted *and* the template apply reverted, the second surface's toast painted behind the open modal where nobody saw it (#2892). Every unit test stayed green, because a per-component test mounts one surface and the collision needs two. Four obligations: **(a)** the innermost surface calls `claimUndoShortcut()` on mount and releases it in the effect cleanup, and every outer handler for the same chord starts with `if (isUndoShortcutClaimed()) return;` — precedence is declared, not inherited from mount order; **(b)** do **not** reach for `preventDefault()`, `stopPropagation()`, or listener ordering as the arbiter — `preventDefault()` stops the *browser's* default action and never a sibling listener, and propagation order depends on whether each site happened to attach to `document` or to `window`, which no contract fixes and any refactor flips; **(c)** the handler still carries the ordinary guards on top of the claim — `isTypingInInput(e.target)` (⌘Z inside a text field means "undo my typing"), and an explicit `e.shiftKey` bail so Shift+⌘Z stays redo; **(d)** test the arbitration at the **registry** seam (`hooks/useGlobalShortcut.test.ts`) — claim/release, nesting, and idempotent release so a double effect-cleanup cannot unclaim a live holder — because no component-level test can reach the two-surfaces-mounted state where the bug lives. This is the same mechanism `claimHelpShortcut` / `isHelpShortcutClaimed` already used to stop the Board and Schedule cheatsheets both answering `?`; the precedent is deliberate, and a chord whose collision costs data rather than an extra dialog has less excuse to invent its own. Generalizes past ⌘Z: any destructive or irreversible global chord (a future ⌘⌫, ⌘S-as-overwrite) gets a claim before it gets a handler. Reference: `hooks/useGlobalShortcut.ts` (`claimUndoShortcut`, `isUndoShortcutClaimed`), `components/import/CsvImportWizard.tsx` (the claimant), `features/schedule/SeedBanner.tsx` and `features/schedule/ScheduleView.tsx` (the yielding handlers).
