# Rule 375 — A shared helper does not stop nine surfaces reinventing a refusal — the PROP TYPE does. When a class recurs …

> **Invariant.** Indexed from [`packages/web/CLAUDE.md`](../../../packages/web/CLAUDE.md), section *Surface states*. The index carries the rule's headline; this file carries its full text (#3744, ADR-0653 amendment). Binding everywhere, not only on the surface that produced it.

**A shared helper does not stop nine surfaces reinventing a refusal — the PROP TYPE does. When a class recurs across call sites of one primitive, change what the primitive ACCEPTS, and let `tsc` refuse the hardcoded string.** #3302 fixed the classification popover and wrote `describeClassificationError` beside it; seventeen days later the identical defect was still live on eight other surfaces (#3332), because a helper one import away is advice and advice does not compile. `DialogFooter`'s `error?: string | null` was the actual mechanism keeping it there: a slot typed `string` can only ever be handed a finished sentence, so every one of its call sites had already thrown the server's reason away *before* the shared component saw it, and each had independently landed on "Save failed" / "Couldn't save — try again". Retyping that one prop to `WriteRefusal | null` fixed four drawers at the seam and made a fifth impossible — this is rule 340's "let the type system refuse it" reached from the other direction, and it is the reason this class needed no sweep and needs no gate. Five obligations.
