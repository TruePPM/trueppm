# Rule 308 — A false capability claim is a property of the SURFACE, not of the sentence you were sent to fix — enumerate …

> **Invariant.** Indexed from [`packages/web/CLAUDE.md`](../../../packages/web/CLAUDE.md), section *Dialogs, focus and keyboard*. The index carries the rule's headline; this file carries its full text (#3744, ADR-0653 amendment). Binding everywhere, not only on the surface that produced it.

**A false capability claim is a property of the SURFACE, not of the sentence you were sent to fix — enumerate every claim on the screen, and pin it with an assertion on the capability rather than on the retired wording.** #2896 was filed against one sentence ("Gate reviews are automatically scheduled when a phase boundary milestone is saved"). Fixing that sentence left three more claims of the same class live on the same screen: the page **subtitle** ("Instances are created when the program starts and linked to milestones"), the panel's **"Available variables"** list, and a `placeholder` using a variable absent from that list. None are delivered by any code — `PhaseGateConfig` and `CeremonyTemplate` are both config-only, `invite_template` has zero readers, and there is no ceremony-instance model at all. Worse, the same branch deleted the subtitle's claim from the *docs* while leaving it in the *app*, so the screen contradicted itself and the product told the lie the documentation had just retracted. Four obligations. **(a) Enumerate before editing** — page subtitle, section paragraphs, empty states, helper text, tooltips, and `placeholder` copy are all claims, as are the panels and modals the surface opens; the reported one is rarely the only one. **(b) A vocabulary is a claim.** "Available variables", "supported formats", "recognized fields" each assert that something consumes them — grep for the *consumer*, not the field, and check the list is at least internally consistent with its own example. **(c) The model/serializer docstring is the source of truth.** When it says "config-only", "out of scope", or "does NOT generate", every UI string derived from that model must agree; both docstrings here said so plainly while the screen above them said the opposite. **(d) Assert the capability, not the phrase.** A guard matching the retired wording (`/automatically scheduled/`) protects nothing — the next claim will be worded differently, which is exactly how the subtitle survived the first pass. Assert the honest copy is **present** and that the *claim* is absent across its plausible phrasings, and cite the docstring establishing the limit in the test comment so the guard dies when the limit does, not when someone rephrases a sentence. Note this class is structurally invisible to `docs:version-accuracy`: the copy names no version, so the gate that catches misleading version claims cannot see it. Reference: `features/settings/program/ProgramCadencePage.tsx`, `features/programs/cadence/PhaseGateConfigPanel.tsx` and their specs (#2896; dispatch tracked as #2983).
