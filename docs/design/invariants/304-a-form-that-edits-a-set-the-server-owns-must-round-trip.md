# Rule 304 — A form that edits a *set* the server owns must round-trip every member — including ones this build has no …

> **Invariant.** Indexed from [`packages/web/CLAUDE.md`](../../../packages/web/CLAUDE.md), section *Controls and composition*. The index carries the rule's headline; this file carries its full text (#3744, ADR-0653 amendment). Binding everywhere, not only on the surface that produced it.

**A form that edits a *set* the server owns must round-trip every member — including ones this build has no widget for. Never narrow a fetched collection to the client's own catalog and then write the narrowed value back.** The pattern that produces silent data loss is small and looks defensive: hydrate state as `new Set(remote.items.filter((i) => LOCAL_CATALOG.includes(i)))`, then `PATCH` the whole list on save. Every member the client did not recognize is deleted, with a success toast and no diff — and the client is not the authority on what is valid, so "unrecognized" reliably means "added by a newer server, or written through the API", not "invalid". This is what the webhook event picker did for two releases: it shipped 11 of the backend's 19 events, so an admin opening an API-created webhook to fix a URL typo destroyed eight real subscriptions (#2883). Three requirements: **(a) hydrate unfiltered** — the fetched collection is the source of truth for what is currently set; **(b) partition, don't filter** — split into "has a widget" and "does not", render the first normally and the second as its own read-and-clear section ("Other subscriptions", explaining they were registered elsewhere and stay unless cleared) so removal is always a deliberate act; **(c) the invariant must hold without a catalog update** — a member added to the server tomorrow, with no frontend change at all, must still survive a save today. A gate that keeps the two catalogs in step is complementary and **not** a substitute: it degrades a future gap from "silently deleted" to "not selectable here", which is the whole point. Note this is the inverse of the usual defensive-filtering instinct — carrying an inert value the server ignores costs nothing; deleting a live one is unrecoverable. Applies to any multi-select bound to a server-owned vocabulary (event subscriptions, labels, scopes, notification channels, feature toggles). Reference: `features/settings/components/integrations/WebhookEditorModal.tsx` + `events.ts`, gated by `test_web_event_catalog_covers_every_backend_event` in `packages/api/tests/apps/webhooks/test_webhook_format.py`.
