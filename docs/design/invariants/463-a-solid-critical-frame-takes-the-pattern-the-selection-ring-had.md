# Rule 463 — When one bar state changes its line pattern, re-check every other state that shared it: a pattern freed in one place is a collision in another

> **Invariant.** Indexed from [`packages/web/CLAUDE.md`](../../../packages/web/CLAUDE.md), section *Signal encoding*. The index carries the rule's headline; this file carries its full text (ADR-0653). Binding everywhere, not only on the surface that produced it.

**When one bar state changes its line pattern, re-check every other state that shared it: a pattern freed in one place is a collision in another.** The schedule canvas tells bar states apart by stroke pattern as well as hue (WCAG 1.4.1). In v1 the critical frame is dashed and the selection ring is solid (#4397). The shell v2 Schedule (#4796) needed a third state, near-critical, and gave it the dashed pattern, which made the critical frame solid. That collided with the solid selection ring: a selected non-critical bar and a critical bar then differed only by hue, and no single-state test could see it. The fix was to give the ring a dotted pattern of its own whenever the v2 at-rest option is on. Four obligations. **(a)** Treat the set of patterns as one table (solid / dashed / dotted / none against critical / near-critical / selected / plain), and when one row changes, check every other row against it. **(b)** Pin the whole table in one renderer test that records the dash in effect at each `stroke()` (`GanttRenderer.test.ts`, "shell v2 at rest"). A per-state assertion passes on exactly the collision this rule describes. **(c)** The DOM legend's swatches draw what the canvas draws, in the canvas's own colors: critical and near-critical are FRAMES around a bar whose fill still shows its state, so their swatches are frames on an empty box, colored from the renderer's `COLOR` / `COLOR_DARK` constants through CSS custom properties, never a Tailwind token that only approximates them. The legend keys no glyph the canvas does not draw: the design gives ▲ (critical) and ◆ (near-critical) to the Float column, and they join the legend only when a pane prints them, with the same meaning. **(d)** Near-critical is one predicate (`isNearCriticalByFloat`, the server's band: `0 < float <= threshold`), shared by the canvas frame and the task drawer, and it answers false until the project's threshold has loaded. A second derivation, or a hard-coded fallback threshold, is how a framed bar and the drawer came to disagree about the same row. Reference: `features/schedule/engine/GanttRenderer.ts` (`criticalAtRest`, `SELECTION_RING_AT_REST_DASH`), `features/schedule/v2/ScheduleLegendV2.tsx`, `features/schedule/nearCritical.ts`.
