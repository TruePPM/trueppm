# Rule 143 — Sage shade discipline (WCAG)

> **Invariant.** Indexed from [`packages/web/CLAUDE.md`](../../../packages/web/CLAUDE.md), section *Color and tokens*. The index carries the rule's headline; this file carries its full text (#3744, ADR-0653 amendment). Binding everywhere, not only on the surface that produced it.

**Sage shade discipline (WCAG).** sage-500 `#4FA884` = **fills only**, always with navy text (navy-on-sage 6.8:1); it is ~2.9:1 on white so it is **never** body text, a foreground icon, or a thin border on a light surface. **sage-700 `#316F57` = foreground text / link / ring / border on light (5.93:1)** — this is what `brand-primary` resolves to in light mode. (sage-600 `#3E8C6D` is only **4.06:1** on white — it fails AA for normal text; it is a *fill/dot* weight, e.g. the on-track `-bg` tint, never foreground text.) sage-400 `#66B998` = text/affordance on **dark**. Putting sage-500 or sage-600 on white as foreground text is a 1.4.3 failure — use sage-700. This includes the **wordmark "PPM"**: it is foreground text, so it uses `text-brand-primary` (sage-700), not sage-500 (rule 142; #1689). The **only** sage-500-on-light usages that are legitimate are *fills* (bar/dot/tint fills with navy text, and the `LogoMark` arrowhead).
