# Rule 236 — A fixed-width "table" row (flex row of w-* cells) that must stay legible on a phone reflows to a two-line card BELOW md using paired md:contents wrappers — and when the list is virtualized, the virtualizer's mobile row height MUST equal the card's fixed mobile height, or the second line is clipped

> **Decision record.** Moved out of `packages/web/CLAUDE.md` by #2433 (ADR-0653): precedent bound to one surface, not a general invariant. It is still binding for the surface it governs.
>
> Original section: *Responsive table→card reflow for the task Grid (Issue #1701)*

**A fixed-width "table" row (flex row of `w-*` cells) that must stay legible on a phone reflows to a two-line card BELOW `md` using paired `md:contents` wrappers — and when the list is virtualized, the virtualizer's mobile row height MUST equal the card's fixed mobile height, or the second line is clipped.** The Grid's rows (`features/grid/{TaskRow,OutlineRow}.tsx`) are a flex row of fixed-width cells (~744px total) that collided and clipped on a phone. The reflow pattern, without duplicating any datum or plumbing an `isMobile` prop into every cell:
 - **Two `md:contents` group wrappers** (`role="presentation"`, so row→gridcell ARIA ownership survives the intermediary): line 1 = WBS/name/owner, line 2 = dates/duration/progress/status. The row is `flex flex-col md:flex-row`; below `md` the wrappers are real flex lines that stack, and at `md`+ they collapse to `display:contents` so the cells lay out as the **byte-identical original desktop table**. Give each cell its width as `md:w-14` (natural width on mobile), not `w-14`.
 - **Virtualized modes (Flat/Grouped via `VirtualRows`) need a breakpoint-aware fixed height.** `VirtualRows` positions each row at a fixed `estimateSize` — it does not measure — so a taller two-line card gets clipped by its slot unless `estimateSize` returns the mobile height. Drive it off `useBreakpoint()==='sm'` (which is "< 768px", correctly covering every phone incl. 320px) and set the row's mobile class to the matching fixed height (`h-14` = 56px = the estimate); call `rowVirtualizer.measure?.()` on breakpoint change. Non-virtualized modes (Outline) use `min-h` and grow freely.
 - **Line 2's shrink-0 cells must sum under the 320px budget (~296px after `px-3`).** Everything on line 2 is `flex-shrink-0` except the progress bar (`flex-1 min-w-[1.5rem]`), so surplus does not wrap — it clips/pushes. The **status pill is what tips a row over**: hide the numeric `%` on mobile with `sr-only md:not-sr-only` (kept for screen readers, since the bar is `aria-hidden`) to reclaim ~34px. Verify with a Playwright spec at a 390px viewport asserting `scrollWidth - clientWidth <= 1` on the scroll container.
 - **Hide the desktop column-header row on mobile** (`hidden md:flex`) — the card is self-describing; and demote low-value columns (Outline predecessors, the phase subtitle) to `hidden md:block`/`md:inline`. Reference: `features/grid/{TaskRow,OutlineRow,VirtualRows,FlatMode,GroupedMode,OutlineMode}.tsx` (#1701).
