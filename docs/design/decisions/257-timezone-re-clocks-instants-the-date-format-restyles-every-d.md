# Rule 257 — Timezone re-clocks instants; the date format restyles every date; a calendar date is never re-timezoned

> **Decision record.** Moved out of `packages/web/CLAUDE.md` by #2433 (ADR-0653): precedent bound to one surface, not a general invariant. It is still binding for the surface it governs.
>
> Original section: *Per-user timezone re-clocks instants; the date format restyles every date (Issue #1953, ADR-0410)*

**Timezone re-clocks instants; the date format restyles every date; a calendar date is never re-timezoned.** A datetime with a time-of-day (`…THH:MM:SSZ`, from a server `DateTimeField`) is an *instant* — format it via `useUserDateFormat().formatInstant` / `formatInstantDate` (re-clocked to the user's timezone AND styled by their date format). A date-only value (`YYYY-MM-DD`, from a `DateField`) is a *calendar date* — format it via `formatUtcDate` (`fmtUtcShort`/`fmtUtcLong`) or `useUserDateFormat().fmtDate*` (UTC-pinned per ADR-0144/rule 189, but styled by the user's date format). **Never apply a user timezone to a calendar date** (it shifts the displayed day per viewer — the ADR-0144 bug) and **never UTC-pin an instant**. The date *format* (`iso`/`us`/`eu`/`auto`) applies to BOTH (a style change is timezone-independent and never moves a day); the *timezone* applies to instants ONLY. Pick the path by the wire shape, not the field's name. The style is single-sourced in `lib/dateFormatStyle.ts`; `formatUtcDate.ts` keeps `timeZone:'UTC'` INVARIANT (never parameterized) and reads a module-level style default that `AppShell`'s `DisplayFormatSync` syncs from the user's `date_format` — so every forecast/CPM/schedule date already routing through `formatUtcDate` (rule 189) reflects the format with no call-site change. A surface that must live-update on a preference change (rather than on next navigation) reads `useUserDateFormat()` instead of the bare functions. Reference: `lib/dateFormatStyle.ts`, `lib/formatUtcDate.ts`, `lib/formatUserDateTime.ts`, `hooks/useUserDateFormat.ts`, `features/shell/DisplayFormatSync.tsx`.
