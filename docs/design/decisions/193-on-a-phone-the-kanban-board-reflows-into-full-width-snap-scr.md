# Rule 193 — On a phone the Kanban board reflows into full-width snap-scroll status columns with a dot-strip map above; the reflow is gated behind isMobile, snap is native CSS (no JS scroll animation), and the phase grouping collapses to a flat per-status list

> **Decision record.** Moved out of `packages/web/CLAUDE.md` by #2433 (ADR-0653): precedent bound to one surface, not a general invariant. It is still binding for the surface it governs.
>
> Original section: *Mobile board reflow (Issue #853, v3 case 8)*

**On a phone the Kanban board reflows into full-width snap-scroll status columns with a dot-strip map above; the reflow is gated behind `isMobile`, snap is native CSS (no JS scroll animation), and the phase grouping collapses to a flat per-status list.** Below `md` (the board's `useBoardDensity().isMobile`, matchMedia `max-width: 767px`) `BoardView` renders `MobileBoard` instead of the desktop phase × status grid — the grid is unreadable on 375px, so each **status column** becomes a full-width page (`min-w-full snap-start`) inside a `snap-x snap-mandatory` scroller, and the phase swimlanes collapse: each column shows a flat list of its cards across every phase (`mobileTasksByStatus`, derived from `phaseTaskMap` so the same task-level filters + sort carry through). Desktop is unchanged — never restyle the grid, branch a new tree behind `isMobile`. **Snap is native**: no JS scroll animation, so it is inherently `prefers-reduced-motion` safe; the only programmatic scroll (strip tap → `scrollIntoView`) downgrades `behavior` to `'auto'` under `prefers-reduced-motion: reduce` (rule 70). The active column is tracked by an `IntersectionObserver` on the scroller (guard `typeof IntersectionObserver === 'undefined'` for jsdom/old browsers — tap-to-jump still works without it). The **dot-strip** (`MobileColumnStrip`) is the map: one `<button>` per column (min-h-44px, rule 5) carrying a health dot (`aria-hidden`, same status-vocabulary color as the desktop column-header dot — rule 6), the column's **first word**, and its count; the active segment's bar fills solid (`bg-neutral-text-primary`) and is marked `aria-current` (the non-color signal — never rely on the bar fill alone). The strip group is `role="group" aria-label="Board columns"`, **not** a tablist (the columns stay mounted; nothing swaps). **Card anatomy, the WIP pill, the critical (red left-border) / blocked treatment, and the status vocabulary are unchanged** — reuse `BoardCard` as-is; only the layout reflows. Reference: `features/board/MobileColumnStrip.tsx` + `MobileBoard` in `BoardView.tsx`.
