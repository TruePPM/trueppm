# Rule 204 — A full-surface "drive the room" overlay (the standup walk-the-board, StandupMode) is a role="dialog" aria-modal="true" and MUST trap focus with useFocusTrap even though it is operated primarily by arrow keys and is often projected — AT users in the room are still real

> **Decision record.** Moved out of `packages/web/CLAUDE.md` by #2433 (ADR-0653): precedent bound to one surface, not a general invariant. It is still binding for the surface it governs.
>
> Original section: *Cloud-file link preview (#571, ADR-0163)*

**A full-surface "drive the room" overlay (the standup walk-the-board, `StandupMode`) is a `role="dialog" aria-modal="true"` and MUST trap focus with `useFocusTrap` even though it is operated primarily by arrow keys and is often projected — AT users in the room are still real.** Four bindings that travel together (any future projected/stepper overlay inherits them): (a) `useFocusTrap(true, onClose)` owns both the Tab cycle and Escape (it listens on `document`) — do **not** also handle Escape in a window `keydown` listener or it double-fires; the window listener carries only the ← / → walk keys so they work without first tabbing to a control. (b) On advance, move focus to the person heading — a `tabIndex={-1}` `<h*>` styled with `focus:` (NOT `focus-visible:`, which a browser may withhold on a *scripted* `.focus()`) so the ring reliably renders. (c) The `aria-live="polite"` `role="status"` region carries the **position only** ("Person N of M") — the teammate name is read by the heading-focus move, so repeating it in the live region double-reads it. (d) The person-rail jump dots are a plain `role="group"` of labeled `<button>`s with `aria-current` on the active one (NOT a `role="tablist"`/`radiogroup`, which would require roving tabindex + in-group arrow handling the window listener already owns); each dot button carries a `min-h-[44px] min-w-[44px]` hit area around a small visual dot (rule 5). Every interactive control in the overlay — Exit, Prev/Next stepper, dots, card rows, links — uses the full rule-4 ring (`focus-visible:ring-2 focus-visible:ring-brand-primary focus-visible:ring-offset-1`) and ≥44px targets (Prev/Next/Exit are `min-h-[44px]`). Reference: `features/board/standup/StandupMode.tsx`, `StandupPersonCard.tsx`, ADR-0166.
