# Rule 175 — An inheritable boolean setting renders as a two-chip inherit/override radiogroup wrapping the shared Toggle, never a bare switch — and the inheriting state surfaces the resolved value as "Inherit (On/Off)"

> **Decision record.** Moved out of `packages/web/CLAUDE.md` by #2433 (ADR-0653): precedent bound to one surface, not a general invariant. It is still binding for the surface it governs.
>
> Original section: *Inheritable boolean settings — Workspace → Program → Project (Issue #978, ADR-0135)*

**An inheritable boolean setting renders as a two-chip inherit/override radiogroup wrapping the shared `Toggle`, never a bare switch — and the inheriting state surfaces the resolved value as "Inherit (On/Off)".** `InheritableToggleField` (`features/settings/components/InheritableToggleField.tsx`) is the boolean analog of `InheritableIterationLabelField` (ADR-0116) and the reference for `public_sharing` / `allow_guests` at program/project scope (ADR-0135, #978). It reuses the **extracted** shared `Toggle` (`features/settings/components/Toggle.tsx`, lifted out of `WorkspaceGeneralPage`) and the **same** chip styling as `InheritableIterationLabelField` — do not fork either.
 - **The override is the raw nullable column** (`value: boolean | null`, `null` = inherit); the page PATCHes `null` verbatim to clear (no string-style `.trim()` coercion — a `boolean | null` is already canonical).
 - **Display is derived from `value` and the parent's resolved `inherited` only** (`effective = value ?? inherited`) so the chip suffix and the switch word can never contradict — this is the #978 unintuitive-toggle fix (the visible word is always state-derived, never a hardcoded "Disabled" beside an on switch). Entering override **seeds from the effective value** (`onChange(value ?? inherited)`), never a blank/false default that silently flips the live state.
 - **The two chips are a native-radio `role="radiogroup"`** (`sr-only` inputs → arrow-key nav + grouping for free; rule 167 satisfied natively, no hand-rolled button radiogroup).
 - **Below role ≥ ADMIN the control is a read-only indicator** (ADR-0133): no radios, no switch — a status dot + the literal word ("On"/"Off") + provenance ("inherited from the workspace default" / "set on this program"), one composite `aria-label` with `aria-hidden` children (rule 171) ending "View only.", body text in `neutral-text-secondary` not `neutral-text-disabled` (rule 169), color never the sole cue (rule 7).
 - Reuse this anatomy for any future inheritable boolean (e.g. a per-scope feature toggle), the same way `InheritableIterationLabelField` is the pattern for inheritable string/enumerated settings.
