# Rule 237 — A collapsed board-column stub must surface a WIP breach with the same always-on visibility as the expanded header's WipBreachChip — breach visibility is independent of the "Show WIP limits" toggle (rule 176 extends to stubs), and an empty folded column must read as empty, never as an ambiguous blank (#1695/#1697)

> **Decision record.** Moved out of `packages/web/CLAUDE.md` by #2433 (ADR-0653): precedent bound to one surface, not a general invariant. It is still binding for the surface it governs.
>
> Original section: *Responsive table→card reflow for the task Grid (Issue #1701)*

**A collapsed board-column stub must surface a WIP breach with the same always-on visibility as the expanded header's `WipBreachChip` — breach visibility is independent of the "Show WIP limits" toggle (rule 176 extends to stubs), and an empty folded column must read as empty, never as an ambiguous blank (#1695/#1697).** A stub is a *lens* on the column, not a place to hide a signal the expanded header shows: collapsing to reclaim width must not suppress scope invisibility. In `ColumnStub` (`features/board/BoardView.tsx`) the two signals are split: (a) the **count badge's limit portion** (`N/limit`) obeys `showWip` — plain `N` when the toggle is off and the column is *not* breaching; (b) the **breach state** (`at` → amber `--semantic-at-risk`, `over` → red `--semantic-critical`) renders **always**, and a breaching stub shows the `N/limit` ratio (tabular-nums) in the breach color regardless of the toggle. The call site therefore passes `wipBand={wipState(count, col.wipLimit)}` computed **unconditionally** (not gated on `showWip`), matching the header's always-on breach chip (ADR-0130 D2). "Folded ≠ empty" (#1697): a populated stub shows a filled `--brand-primary` count pill; a 0-card column shows a **dashed hollow "0"** (`border-dashed`, no fill) with the accessible name `"…, empty"`. The stub `aria-label` encodes the breach (`"…, over WIP limit of 5"`) so the signal survives for screen readers too. Reference: `ColumnStub` in `BoardView.tsx`, `wip.ts::wipState`.
