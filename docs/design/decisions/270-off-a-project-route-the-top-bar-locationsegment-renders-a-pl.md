# Rule 270 — Off a project route the top-bar LocationSegment renders a *placeholder picker* (no current), not a distinct control — so a project is one hop from anywhere while there is still exactly one wayfinding surface (ADR-0203)

> **Decision record.** Moved out of `packages/web/CLAUDE.md` by #2433 (ADR-0653): precedent bound to one surface, not a general invariant. It is still binding for the surface it governs.
>
> Original section: *Off-project `LocationSwitcher` project segment is an unanchored placeholder picker (Issue #2102, ADR-0508 D3)*

**Off a project route the top-bar `LocationSegment` renders a *placeholder picker* (no current), not a distinct control — so a project is one hop from anywhere while there is still exactly one wayfinding surface (ADR-0203).** `useLocationModel` builds a `projectSegment` even when `projectId` is undefined: from the already-loaded membership-wide `projects` list, with `currentId`/`currentName`/`currentMethodologyLabel` all `undefined` and options landing on each project's `/projects/:id/overview`. `LocationSwitcher` passes `placeholder="Jump to project…"` (ellipsis char) and `placeholderAriaLabel="Jump to a project"` — the trigger + listbox take that accessible name, **never** the `Switch project` fallback (which implies a current project exists). Three invariants a refactor must preserve: **(a)** the `options.length < 2` static-identity-row shortcut in `LocationSegment` applies **only when a current exists** — placeholder mode renders the searchable picker even with a single option, because with no current every option is a destination and a static placeholder that opens nothing is the dead affordance rule 124 forbids; the guard is `currentId === undefined && placeholder !== undefined`, gated on the `placeholder` prop (not `currentId` alone) so a caller that omits it — e.g. the program segment mid-load, `currentId` transiently undefined — keeps its original static-row / `Switch …` behavior and this branch only touches segments that opted in. **(b)** with **zero** projects the segment is omitted entirely (`projectSegment` returns `null`), collapsing to the leaf alone — leaf-only wayfinding, no empty picker. **(c)** the off-project anatomy is two-part `[Jump to project…] › <Leaf>` — a program route keeps its program-picker-only anatomy (`effectiveProgramId` short-circuits the placeholder branch), introducing no third segment. It **keeps** self-suppressing on `/settings/*` (rule 123), and on mobile stays non-interactive leaf-only wayfinding (the mobile branch reads `project.currentName`, which is undefined in placeholder mode). Reference: `features/shell/{useLocationModel.ts,LocationSegment.tsx,LocationSwitcher.tsx}`.
