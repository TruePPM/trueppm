# Rule 258 — A single-value selector over a large enumerable set (timezones, locales, currencies — anything ≳50 options where the label is a compound Group/Item string) uses the rule-124 trigger + popover + searchable-listbox pattern, never a native <select>

> **Decision record.** Moved out of `packages/web/CLAUDE.md` by #2433 (ADR-0653): precedent bound to one surface, not a general invariant. It is still binding for the surface it governs.
>
> Original section: *A large enumerable single-value selector is a searchable combobox, not a native `<select>` (Issue #1953)*

**A single-value selector over a large enumerable set (timezones, locales, currencies — anything ≳50 options where the label is a compound `Group/Item` string) uses the rule-124 trigger + popover + searchable-listbox pattern, never a native `<select>`.** A native `<select>`'s built-in type-ahead only prefix-matches the option text, so a user cannot find `Europe/London` by typing `london` — the compound-id case fails exactly the search users reach for. Render a trigger `<button>` showing the current value (`aria-haspopup="listbox"`, `aria-expanded`, rule-4 ring, `h-11`) opening a popover with a `role="combobox"` search input (`focus-within` ring, rule 124/157) over a `role="listbox"` filtered by **case-insensitive substring on the whole id** (match `europe` *and* `london`). An "Automatic / detected" sentinel option is pinned as the first row **above a divider and exempt from the filter** so the user can always return to it; its label embeds the resolved value (`Automatic — detected: {Intl…timeZone}`). Empty result is a `role="status"` row. Reuse the rule-124 `SettingsContextSwitcher` (trigger/open/close/focus-return) and `ResourceSearchCombobox` (listbox internals) patterns. Corollary: an **enumerated display-format** choice (date/number/time format) is a native-radio `role="radiogroup"` (rule 167) that renders a **live sample of real current data inline per option** (right-aligned `.tppm-mono`) so all formats are compared at a glance, with a non-color note column ("Year first" / "Month first") differentiating options whose samples can coincide (rule 6). Reference: `features/me/TimezoneFormatSection.tsx`.
