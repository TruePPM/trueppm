# Rule 249 — Below md the Schedule renders a dedicated DOM list-timeline (features/schedule/mobile/MobileSchedule.tsx), not the desktop canvas Gantt — a mutually-exclusive isMobile branch, the same reflow discipline as MobileBoard (rule 193)

> **Decision record.** Moved out of `packages/web/CLAUDE.md` by #2433 (ADR-0653): precedent bound to one surface, not a general invariant. It is still binding for the surface it governs.
>
> Original section: *Modal focus traps: multi-state dialogs re-seat via focusKey; nested confirm dialogs own their own trap (Issue #1776)*

**Below `md` the Schedule renders a dedicated DOM list-timeline (`features/schedule/mobile/MobileSchedule.tsx`), not the desktop canvas Gantt — a mutually-exclusive `isMobile` branch, the same reflow discipline as `MobileBoard` (rule 193).** The canvas engine (rules 59–85) is mouse-and-pixel native; on a phone it opens on whitespace with unreadable bars (#1671, ADR-0348). The mobile surface is a vertically-scrolling, WBS-ordered list: each row is a two-line touch target (≥44px) — line 1 identity (critical **rail**, shortId, name, Blocked badge, dates) + a 44px one-tap complete; line 2 a **shared-project-window** mini-timeline strip (all rows share one scale so they read as a cascade; per-row scales are banned — they make every bar identical). Placement math lives in the pure, unit-tested `mobileScheduleGeometry.ts` (`leftPct`/`widthPct` as % of the window, 0.75% min bar). **It is a READ/NAVIGATE surface** (ADR-0348): no inline reschedule, no drag-to-schedule; a row tap opens the shared `TaskDetailDrawer` via `scheduleStore.setSelectedTaskId` (the row is an **overlay `<button>` with `absolute inset-0`**, and the complete control is a **sibling** `pointer-events-auto z-10` button — never a `<button>` nested in a `<button>`, which is invalid HTML). Critical = border/rail + redundant glyph, never fill (rules 234/235); progress = fill. The desktop `UnscheduledGutter` (drag-to-schedule) is replaced by a tap-to-open **Unscheduled tray** (collapsible, `localStorage` key `trueppm.mobile.schedule.unscheduled.collapsed`, auto-expand on 0→>0). Offline schedule writes are deferred to the native app — the surface edits online only. Never restyle the canvas to "fix mobile"; branch a new tree behind `isMobile`. (This slot previously held the #1787 quick-win exemption — mobile `fitToProject()` + folded Gantt toolbar; that code was removed with the mobile canvas, which this surface supersedes.)
