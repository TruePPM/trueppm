# Rule 180 — A backlog story's sprint-commitment state is one chip with a fixed precedence, color is the brand accent (never the on-track green), and the "By epic / Ranked" toggle gates drag

> **Decision record.** Moved out of `packages/web/CLAUDE.md` by #2433 (ADR-0653): precedent bound to one surface, not a general invariant. It is still binding for the surface it governs.
>
> Original section: *Product Backlog sprint-state + ranked view (Issue #1223)*

**A backlog story's sprint-commitment state is one chip with a fixed precedence, color is the brand accent (never the on-track green), and the "By epic / Ranked" toggle gates drag.** `SprintCommitmentChip` (`features/project/backlog/components/atoms.tsx`) is the single source for a story's sprint state on the Product Backlog grooming view, with strict precedence: `sprintPending` → the shared `PendingAcceptanceChip` (ADR-0102, rule 149 — the more specific state wins so the two pills never double up on one row); else `sprintId` set → **"Pulled"** (`bg-brand-primary/10 text-brand-primary`); else **"Proposed"** (dashed-outline neutral, the recessive default). "Pulled" uses the brand sage accent **deliberately not `semantic-on-track`** — the green DoR "Ready" chip sits in the adjacent Readiness column and two greens on one row read as a single cue (rule 7/8). Every chip carries its text label (rule 7/120 — never color alone). The header subtitle is data-derived (`{N} pulled into sprint · {M} proposed{ · {K} pending}`), never a static string. The **"By epic / Ranked"** segmented control (sr-only native radios → arrow-key roving for free, rule 175/167; persisted to `localStorage['trueppm.backlog.view']`) switches between the epic-grouped **draggable** view and a **flat, read-only** list in score order ("score drives the ranked view" — manual drag-reorder lives in the By-epic view only; ranked replaces the drag handle with a static rank number and shows the parent-epic **name** as a per-row breadcrumb, since the ID column already carries the story short-id and the epic group header is gone — the rule-959 no-redundant-tag lesson). The assignee avatar (`AssigneeAvatar`, same atoms file) is decorative initials (rule 6 — the assignee name / "Unassigned" is the wrapper `aria-label`); 2+ assignees stack a `+N` overflow. The epic-header points **progressbar** pairs the `{done}/{total} pts · {pct}%` text with a `role="progressbar"` bar (rule 120 — value + label, not color alone). Deferred (needs a Release model that does not exist — ADR-0099 Product Owner surface, #758/#1214 at 0.7): the epic `R1 · Jul` release/target-date line.
