# Rule 176 — A delivery forecast branches on forecast_basis, never the legacy basis; flow charts use Recharts with CSS-var tokens and an sr-only summary; suppressed flow metrics render a content-free wall and an in-audience flow panel carries a legible "aggregate only" caption

> **Decision record.** Moved out of `packages/web/CLAUDE.md` by #2433 (ADR-0653): precedent bound to one surface, not a general invariant. It is still binding for the surface it governs.
>
> Original section: *Flow analytics & flow forecasts (Issue 1188, ADR-0137 / ADR-0130)*

**A delivery forecast branches on `forecast_basis`, never the legacy `basis`; flow charts use Recharts with CSS-var tokens and an `sr-only` summary; suppressed flow metrics render a content-free wall and an in-audience flow panel carries a legible "aggregate only" caption.** The sprint-forecast contract carries two fields: `basis` is frozen at the legacy `"monte_carlo"` constant (kept only for back-compat) and **must never be branched on**; `forecast_basis` (`"velocity" | "throughput"`, ADR-0130 D3) is the discriminator. A `throughput` forecast is a continuous-flow team — render it in **item/week/date** vocabulary (`remaining_count`, P50/P80/P95 *dates*), never sprint/points language; `status: "insufficient_flow_history"` gets an explanatory line ("needs ≥4 weeks of completed-work history"), never a blank widget. Both bases are real Monte Carlo, so P50/P80/P95 percentile vocabulary stays honest (rule 166 reserves percentiles for simulation, which both are). Reference: `SprintForecastWidget`/`SprintForecastChips` (the branch), `FlowAnalyticsPanel` (`features/board/`). Flow charts (CFD stacked area, weekly throughput bars) use **Recharts with `var(--color-*)` fills + `isAnimationActive={false}`** (mirror `BurnChart`, never raw hex — the design-system-v2 hex gate), and every chart carries a `<p className="sr-only">` text summary (WCAG 1.1.1; charts are `aria-hidden`). Cycle/lead time is a **P50/P80/P95 stat strip, not a histogram** — the endpoint returns percentiles, not buckets. The historical distributions are team-private (ADR-0104 `flow_metrics`, TEAM/TEAM): when `flow_metrics_suppressed` the panel body is a content-free wall (rule 165), and when in-audience it shows a legible `🔒 Team-private · aggregate only — no individual breakdown` caption (the privacy guarantee must be visible, not doc-only). Forecast **dates stay visible** under suppression — only the series are gated. The panel is **collapsed by default** (localStorage-persisted) and only fetches once expanded. The per-column WIP breach chip (`WipBreachChip`) renders on `at`/`over` **independent of the "Show WIP limits" toggle** (a breach is a signal, not an opt-in detail) and is `aria-hidden` because the column `<h2>` accessible name already announces the breach.
